01

功率半导体及集成电路

电子信息

核心问题国产器件在车规/工业级到底替代到什么程度，哪些规格仍必须用国外原厂

这个产业赚的是「每一度电被搬运时开关损耗」的钱：把电变换得更省、更小、更耐用的器件与模块。硬件工程师和 FAE 在一线干活，事卡在国产件「参数表对得上、装上板子不敢用」，替代的证据链散落在各家实测里，没人汇成一张能查的账。

细分方向MOSFET/IGBTSiC/GaN功率IC驱动与封装
典型用户器件研发工程师整机硬件工程师采购与供应链FAE现场应用工程师投资与产业研究
重庆锚点华润微电子重庆基地（西部科学城/西永）：功率半导体 IDM，公开口径 50 余款车规功率芯片量产万国国际半导体两江新区 12 英寸功率器件基地（公开投资约 71.7 亿元），是特色工艺产能向 12 英寸迁移的行业样本重庆超硅半导体（两江）：大尺寸半导体硅片，材料环节的本地配套下游牵引：长安、赛力斯所在的智能网联新能源汽车集群带来车规器件本地需求；产业地图口径 2025 年重庆集成电路产量同比增长 47.2%

产业核心做电能变换的核心开关器件与配套芯片（MOSFET/IGBT/SiC/GaN、栅极驱动 IC、功率模块），靠更低的损耗、更高的功率密度和车规级可靠性赚钱。

产业链地图

上游原料 / 部件 / 设备

衬底与外延材料

8/12 英寸硅片、SiC 导电型衬底与外延片、GaN 外延

重庆超硅、沪硅产业、天岳先进、天科合达等SiC 衬底占器件成本近半，6→8 英寸是成本分水岭；衬底缺陷直接决定良率
关键工艺设备

光刻、刻蚀、离子注入、减薄抛光、激光退火、键合/烧结封装设备

ASML、应用材料、中微公司、北方华创、盛美上海等功率特色工艺不追先进制程，但薄晶圆减薄、激光退火等功率专属设备是独有瓶颈，交期长
EDA 与 TCAD

器件级 TCAD 仿真、元胞与终端结构设计辅助

Synopsys（Sentaurus）、Silvaco、华大九天等功率器件设计强依赖 TCAD，这一环节国产化程度比数字 EDA 更低
检测与车规认证

可靠性试验（HTRB/功率循环/温循）与 AEC-Q101、AQG324 认证测试

赛宝实验室、中汽研、TÜV/UL 等认证是进车规的门票，实验室排期与报价不透明，是器件厂共同的排队点

中游制造 / 集成 / 流通

芯片设计（器件/功率IC）

MOSFET/IGBT/SiC 元胞与终端设计、栅极驱动与电源管理 IC 设计

士兰微、新洁能、东微半导、杰华特等设计公司及各 IDM 内部设计部门元胞设计 know-how 藏在自己的流片数据里，公开文献只报最优值
晶圆制造（特色工艺 IDM/代工）

6/8/12 英寸功率器件晶圆制造（超结、沟槽 IGBT、BCD、SiC）

华润微（含重庆基地）、华虹、芯联集成、万国半导体（重庆 12 英寸）等8 英寸是功率主力、12 英寸降本是主线；重庆定位特色工艺，产业地图口径 2030 年目标晶圆产能 30 万片/月
封装与功率模块

分立器件封装（TO 系列等）与功率模块（62mm 标准、定制水冷）封装

斯达半导、士兰微、扬杰科技、宏微科技及 IDM 自有封测线封装寄生参数与散热决定芯片性能能否兑现；银烧结、铜线键合是新一代工艺分水岭
测试与可靠性筛选

静态/动态参数测试、车规筛选、批次参数分布数据管理

IDM/封测厂测试中心、专业测试代工厂双脉冲等动态测试的设备与相关性调校是门槛，车规要求全批次可追溯

下游应用 / 服务 / 终端

新能源汽车

主驱逆变器、车载充电机 OBC、DC-DC、热管理系统的功率级

比亚迪、长安、赛力斯及各电驱系统供应商单车功率器件价值量最高、认证壁垒最深；重庆整车集群是本地器件的天然验证场
光伏储能与充电桩

组串逆变器、储能 PCS、充电模块

阳光电源、华为数字能源、英飞源等对效率与成本双敏感，是 SiC 器件放量的第一梯队场景
工业驱动与电源

变频器、伺服、UPS、通信电源的功率单元

汇川技术、台达、麦格米特等工业级认证周期短于车规，是国产器件导入的主战场和进入车规前的跳板
消费电子

产业基金、券商研究、地方政府平台公司公开信息水分大，「规划产能」与「车规定点」的含金量核验是普遍需求

S01

新平台立项时的功率器件技术路线初选

整机硬件工程师
触发事件

新一代 800V 主驱或大功率充电模块立项，效率与功率密度指标提高，要先定「硅 IGBT、超结 MOSFET、SiC 还是 GaN」的路线

当前做法

搜行业白皮书与竞品拆解报告 → 拉几家头部厂商的参考设计 → 粗算损耗与成本 → 带着一版对比 PPT 和系统、成本同事开会拉扯

所需数据

目标工况（电压/功率/开关频率）、竞品方案、各家应用笔记、价格线索

决策参数

开关频率与损耗、SiC 与硅的价差、驱动复杂度、供应链安全、量产成熟度

具体痛点

公开资料全是厂商立场的「能省多少损耗」，没有人给你一张按工况归一的完整账——器件价差之外还有驱动、散热、EMC 整改的隐藏成本

错误成本

路线选错，一代平台 2～3 年被锁死，中途改路线等于重新开发

现有替代

信原厂参考设计 + 听代理商推荐（各有立场）

季网站可解证据中
SiC vs IGBT800V平台技术路线参考设计损耗对比
🖥 按工况（电压/功率/频率）归一的路线对比决策器：损耗、器件+驱动+散热全成本、成熟度放进同一口径的对比表
S02

在二十多页 datasheet 里跨厂商逐行比对关键参数

整机硬件工程师
触发事件

初选池里有 5～8 款候选器件，要把范围收敛到 2～3 款拿样

当前做法

逐个下载 PDF → 手工把 RDS(on)、Qg、Eoss、SOA、Rth 抄进 Excel → 发现各厂测试条件不一样 → 硬着头皮换算或干脆按品牌名气收窄

所需数据

各厂 datasheet PDF、应用笔记里的测试条件定义

决策参数

RDS(on)@Tj、栅电荷 Qg/Qgd、开关能量 Eon/Eoff、热阻 Rth(j-c)、短路耐受、雪崩能量

具体痛点

有的厂标 25℃ 有的标 150℃，typ 与 max 混用，Qg 测试电压各不相同；二十多页 PDF 翻完一下午，仍不确定数字之间可不可比

错误成本

选型偏乐观，样机阶段效率或温升不达标，改版一轮一个月

现有替代

电商网站的参数表（抓取错漏多）+ 自己维护的 Excel 对比表

周网站可解证据高
RDS(on)对比栅电荷SOAdatasheet选型
🖥 结构化参数库：每项参数连同测试条件原文一起入库，对比时自动提示「25℃ vs 150℃、typ vs max 不可直接比」并给出归一换算
S03

给进口主料找国产第二源并推动内部验证

整机硬件工程师
触发事件

采购要求关键器件双源化，或原厂交期恶化，需要拿国产件对标现用进口型号

当前做法

问代理要 cross 列表 → 对国产厂 datasheet 的头部参数 → 要样品上评估板 → 发现封装引脚或 SOA 曲线对不上 → 改板重新验证，流程走几个月

所需数据

现用型号 BOM 与实测波形、国产厂规格书与样品、内部验证清单

决策参数

封装兼容性（引脚/尺寸/开尔文源极）、参数偏差带、SOA 与短路能力、批次一致性、价差

具体痛点

cross 列表是销售口径，「参数相等」不等于「能直接替换」；内部对国产件的信任只能靠一轮轮实测攒，每换一家都从零开始

错误成本

替代验证拖半年以上；激进替换则可能在客户端批量化出质量事故

现有替代

代理给的 cross 表 + 电商样品 + 自己排期验证

月部分可解证据高
国产替代second sourcepin to pin车规认证双源
🖥 替代比对器输出「参数/封装/SOA 逐项差异 + 风险标注」完成初筛；装机实测与车规审核仍必须线下
S04

搭双脉冲平台实测开关波形

整机硬件工程师
触发事件

新器件到样，或两颗器件「纸面打平」，要实测 Eon/Eoff、体二极管 Qrr 与开关振铃

当前做法

画母排与门驱板 → 找齐差分探头和罗氏线圈 → 逐轮调 Vgs/Rg/母线电压拍波形 → 与 datasheet 曲线对不上再回头排查

所需数据

器件样品、门驱板、母线电源、示波器与探头、datasheet 标注的测试条件

决策参数

Vgs 正负压、内外 Rg、母线电压电流、结温、Eon/Eoff/Qrr 的积分窗口

具体痛点

平台寄生电感与探头带宽都会让结果偏移，实测和原厂标称值差两三成时说不清是谁的问题

错误成本

判读失误导致驱动参数设错，量产端失效

现有替代

委托原厂或实验室代测（排队数周），或直接信 datasheet

月必须线下证据高
双脉冲Eon Eoff开关损耗Qrr探头
⛔ 线下原因：测试依赖台架、探头与真实母线环境，寄生效应当场才测得出——网站只能做测试方法标准、波形参考库与判读 checklist
S05

仿真做不下去——国产器件没有模型

整机硬件工程师
触发事件

项目要求先仿真后投板，PLECS/LTspice 的损耗与热仿需要器件模型

当前做法

进口件能下到官方 SPICE 与热模型 → 国产件官网只有 PDF datasheet → 自己按典型值捏模型 → 仿真结论没人敢信，最后仍靠实测兜底

所需数据

datasheet 参数、厂商模型库（或缺失）、仿真软件

决策参数

模型对开关瞬态的还原度（Qrr、Coss 非线性、Vth 温漂）

具体痛点

没有模型就没有「先仿真收敛再投板」的可能，选国产件被迫多打一轮样、多等一个月

错误成本

多一轮投板验证，项目周期加 1～2 个月

现有替代

手工建模再拿实测定标，或干脆放弃仿真

月部分可解证据中
SPICE模型LTspicePLECS器件模型仿真

S06

SiC 栅极驱动设计：负压、米勒钳位与保护

整机硬件工程师
触发事件

从硅 IGBT 切到 SiC MOSFET，栅极对 dv/dt 和负压敏感，驱动方案要整体重设计

当前做法

翻各家应用笔记 → 选隔离方案与驱动 IC → 算 Rg 与死区 → 画板打样 → 遇到误导通或振铃再改板

所需数据

器件栅极特性（Qg、Vth、允许 Vgs 范围）、隔离器件 CMTI、母线 dv/dt

决策参数

关断负压（-2～-5V）、米勒钳位、退饱和保护阈值与响应时间、隔离 CMTI 等级、死区

具体痛点

应用笔记各说各话，参数窗口窄，「既关得牢又不振铃」要靠板子一轮一轮试出来

错误成本

误导通引起桥臂直通炸管，损失样机并拖垮进度

现有替代

抄原厂评估板电路 + FAE 口头经验

季网站可解证据中
SiC驱动米勒钳位负压关断CMTI退饱和
🖥 驱动参数计算器（Rg/死区/负压/保护阈值）+ 按拓扑分类的设计要点库与失效案例对照
S07

EMC 传导超标后的整改循环

整机硬件工程师
触发事件

样机送预测试传导或辐射超标，被指与开关 dv/dt 和共模路径相关

当前做法

加大 Rg 降 dv/dt → 效率掉了 → 加 snubber → 发热又上来 → 改共模滤波与布局 → 再进暗室排队复测

所需数据

频谱图、近场探头排查记录、驱动与吸收回路参数

决策参数

dv/dt、共模电流路径、Y 电容与共模电感取值、效率损失预算

具体痛点

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 跨厂商参数比对：把各家中英文 datasheet 按统一测试条件归一，自动提示不可比项（25℃ vs 150℃、typ vs max）
  • 替代初筛：进口料号 → 国产候选的逐项差异清单（参数/封装/SOA/认证状态），替代验证不用每次从零翻表
  • 选型计算器：损耗、结温/热阻、SOA 校核一条龙，输出能直接放进设计评审的报告
  • 认证与车规状态导航：AEC-Q101/AQG324 测试项中文拆解、实验室档期与报价档案、认证状态可查
  • 行情与渠道档案：料号级价格带/交期历史、渠道信誉与翻新货图鉴（非实时承诺，逐条标注来源与日期）
  • 失效模式图鉴与 8D 模板：形貌照片↔机理↔典型误用对照，帮 FAE 和质量工程师快速定向

🚧 必须线下 / 网站只能辅助

  • 双脉冲、EMC、温升等实测：依赖台架、暗室与真实负载，网站只能给方法标准与波形参考库
  • 失效分析与竞品切片：开盖、X-ray、SEM 在实验室完成，责任裁定在线下谈判桌上
  • 车规体系审核与定点谈判：PPAP、审厂、商务条款决定生意，线上给不了信任
  • 产线工艺与良率爬坡：薄晶圆、银烧结等强绑定本线设备参数，无法在线复现
  • 现货验真与产能配额博弈：开盖电测验真必须物理进行，配额与成交价在渠道私下完成

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

硬件工程师带着「这款国产料能不能顶替进口主料」来 → 替代比对器逐项输出参数/封装/SOA 差异与风险标注 → 顺路查认证状态与同场景验证案例 → 把自己的双脉冲/温升实测按统一格式回传 → 档案越厚替代验证越快，原厂为拿设计导入主动维护自家对比页

  • 器件参数库（型号/厂商/电压电流/RDS(on)/Qg/SOA/热阻/封装/测试条件原文与 datasheet 版本）
  • 替代对照库（进口料号↔国产料号/逐项差异标注/验证状态/提交者）
  • 认证档案库（AEC-Q101/AQG324 测试项/实验室/状态/可核验来源）
  • 失效案例库（失效模式/应用场景/根因类别/脱敏描述）
  • 渠道与行情档案（渠道类型/授权状态/报价与交期记录/日期）
信任来源
  • 每个参数引用 datasheet 原文页码与版本号，typ/max 与测试条件同列展示
  • 替代差异逐项标注「等效/偏差/缺失」，不给笼统的「可替代」结论
  • 认证与量产状态只挂公开可核验来源（公告/证书编号），查不到就明写「未核实」
  • 实测回传数据强制附测试条件（Vgs/Rg/母线电压/结温），缺条件的不并入档案
