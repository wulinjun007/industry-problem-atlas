电子信息

核心问题除文旅曝光项目外哪些行业应用能形成复购，内容成本怎么降下来

这个产业赚「把现实搬进头显」的钱：硬件厂商卖机器，内容团队接单做项目，线下门店卖票；事卡在客户一单一议做完没复购，内容靠人天堆出来、成本压不下去。

用户角色地图 谁在干活、被考核什么、卡在哪

XR内容开发者
是谁

在内容工作室或企业 XR 团队用 Unity/UE 做 VR/AR 应用开发

被考核

帧率与发热达标、版本按期交付、崩溃率

用什么干活

Unity/UE、Profiler 性能分析器、真机调试、ADB 日志

最常见卡点

PC 上顺滑的 demo 装进一体机就掉帧发热，每个机型的性能经验都要自己踩一遍

三维美术师
是谁

在内容公司或外包团队负责建模、贴图、实景扫描与资产优化

被考核

资产交付量、面数与贴图预算达标率、返工次数

用什么干活

Blender/3ds Max、Substance、摄影测量与重建工具、引擎

最常见卡点

客户要电影级画面，移动头显的渲染预算只够低模，资产量大到做不完

创意制作人
是谁

在创意设计机构或内容工作室负责 VR 项目提案、报价与制作统筹

被考核

签约额、项目毛利、客户满意度

用什么干活

PPT、分镜工具、工时表、往期案例包

最常见卡点

客户一句「要个 VR 的」就要出报价，评估漏一项就亏；项目做完难有二期

文旅项目负责人
是谁

在景区/博物馆/商业综合体负责沉浸项目的立项、采购与运营

被考核

引流人次、票务收入、领导验收满意

用什么干活

供应商方案书、考察清单、票务系统后台

最常见卡点

项目按宣传预算立项，上线热闹一阵就没预算了，更新内容没人出钱

教育信息化负责人
是谁

在中小学/职校/实训基地负责 VR 装备采购与教学落地

被考核

装备使用率、示范课完成情况、安全事故为零

招标参数模板、教材目录、装备展、供应商演示机

最常见卡点

设备买回来内容与教材对不上，老师嫌麻烦不愿用，装备吃灰成检查扣分项

在制造企业或服务商团队做数字孪生、AR 远程协助项目

OPC UA/Modbus 调试工具、BIM/CAD 软件、孪生平台、Excel

消费者不试不买、试了嫌贵；体验点摆着没人来，线上种草的转化追不到门店

S01

新项目立项选引擎和目标机型

XR内容开发者
触发事件

客户要求内容同时覆盖两款一体机和一款 AR 眼镜，团队要先定引擎和最低可跑机型

当前做法

翻厂商官网参数 → 到论坛帖子里捞零散实测 → 找同行打听 → 自购样机回来逐台测

所需数据

目标机型清单（芯片/分辨率/刷新率）、内容类型、客户预算

决策参数

GPU 算力与散热降频策略、PPD、追踪方案、平台商店政策

具体痛点

官网参数口径不一（FOV 怎么量、重量含不含头带），实测帧率数据散落在论坛回复里；样机一台几千元，试错全算成本

错误成本

选错机型返工移植，一个版本两周起步

现有替代

买齐主流样机自测 + 同行群里挨个问

月网站可解证据高
VR一体机对比骁龙XR2PPD选型
🖥 统一测量口径的机型参数实测库（标注测量方法/固件版本/贡献者），按内容类型给可跑基线推荐
S02

上真机就掉帧发热，逐项压渲染预算

XR内容开发者
触发事件

PC 上 120 帧的 demo 装进一体机，跑半小时烫手降频，帧率掉到 60 以下

当前做法

抓帧分析 draw call 与 overdraw → 烘焙光照、砍面数、合图集 → 每改一轮真机复测一轮

所需数据

帧分析数据、机型发热曲线、资产面数与贴图规格

决策参数

单眼分辨率、注视点渲染支持、降频阈值、场景 draw call 上限

具体痛点

每个机型「能跑多少」没有公开基准，经验锁在各家工作室手里；一轮优化两天起步，改完还要真机验证

错误成本

交付延期，体验卡顿直接被客户毙掉

现有替代

论坛零散帖 + 自建基准场景逐机型手测

周部分可解证据高
VR性能优化掉帧发热降频DrawCall注视点渲染
🖥 网站汇集各机型实测基准（统一基准场景的帧率-温度曲线）与优化检查清单；具体调优只能在自家工程里做
S03

一套内容上多个平台，商店规则各一套

XR内容开发者
触发事件

合同写明要覆盖两三个头显平台再加 PC VR，平台 SDK、输入映射、审核规则互不相同

当前做法

逐平台适配 SDK 与交互 → 维护多套分支 → 提审 → 等结果 → 按驳回理由改了再提

所需数据

各平台 SDK 文档、审核规则、机型兼容列表

决策参数

分成比例、审核周期、手柄/手势输入差异、系统版本碎片化

具体痛点

平台政策与驳回标准不透明，一套内容养三套分支；审核卡一周，上线档期就错过

错误成本

上线延期错过营销节点，多平台维护人力翻倍

现有替代

只做主力平台，其余让客户自己想办法

月网站可解证据中
平台移植商店审核分成比例OpenXRSDK
🖥 平台政策对比库（分成/审核时长/驳回原因分类/机型兼容矩阵），政策更新订阅提醒
S04

试玩的人喊晕，不知道该改哪里

XR内容开发者
触发事件

客户验收组织员工试玩，一半人说头晕，领导当场皱眉

当前做法

平滑移动改瞬移 → 加视野缩晕 → 再提帧率 → 重新拉一批没玩过的人复测

所需数据

试玩者反馈记录、帧率与延迟日志、移动方案参数

决策参数

帧率下限、跟手延迟、缩晕幅度、加速度曲线、场景参考系

具体痛点

晕不晕因人而异，只能拉真人一轮轮试；系统性的舒适度设计规范多是英文论文与零散博客，中文一线经验难找

错误成本

验收被拒，整改返工以周计

现有替代

团队内部互相试 + 凭个人经验

月部分可解证据中
晕动症舒适度瞬移移动视野缩晕VR体验设计
🖥 网站汇总公开研究与一线经验的舒适度设计规范和自查清单；真人实测环节必须线下组织
S05

项目要几百个模型，预算根本做不完

三维美术师
触发事件

报价被砍一半后按人天排产，资产量明显做不完，必须找素材库或 AI 生成抄近路

当前做法

翻素材库挑现成的 → 风格对不上 → 试 AI 生成 → 拓扑和 UV 乱要重修 → 兜一圈还是手工返工

所需数据

资产清单、素材库授权条款、AI 工具输出

决策参数

风格一致性、面数与贴图预算、商用授权范围、单件成本

具体痛点

各家素材库授权条款各写各的（能不能商用、能不能改、要不要署名），核实一遍比建模还累；AI 生成资产返工率不低

错误成本

资产超支或授权纠纷，验收时被追责

现有替代

全手工建模 + 加班硬顶

周网站可解证据中
3D素材授权AI生成3D资产制作外包低模
🖥 素材库授权条款结构化对比（商用/修改/署名/独占）+ 使用者实测质量与返工率档案
S06

客户的 BIM/CAD 模型进不了引擎

三维美术师
触发事件

数字孪生项目拿到设计院的 Revit 模型与工厂 CAD 图，要求做成实时 3D 大屏

当前做法

导出中间格式 → 材质丢、坐标系错、面数爆炸 → 手工清理 → 重做 LOD → 和设计院来回扯皮

所需数据

Revit/CAD 源文件、材质贴图、坐标与单位约定

决策参数

面数预算、坐标系与原点、材质映射表、构件粒度

具体痛点

设计软件与实时引擎之间没有可靠的直通管线，转换损耗全靠人肉补，每个项目的清理规则都要重摸

错误成本

资产环节吃掉项目三分之一工期；按「转换很轻松」报的价直接亏损

现有替代

买轻量化软件年费授权 + 专人专职清理

周部分可解证据高
BIM轻量化Revit转Unity格式转换LOD数字孪生建模
🖥 网站做转换工具实测对比（丢什么/留什么/耗时）与清理规则清单；具体模型仍要逐个处理
S07

把真实景区一比一搬进 VR：实景采集与报审

三维美术师
触发事件

文旅客户拍板要「一比一还原」核心景点，路线定为无人机航测建模或高斯泼溅

当前做法

申请空域与景区拍摄许可 → 分架次采集 → 重建 → 数据几十上百 GB 导不进引擎 → 压到能跑为止

所需数据

景区许可文件、航拍影像、重建软件输出、机型性能预算

决策参数

采集精度、数据体积、加载时长、许可范围与用途限制

具体痛点

报审与重建调参都是现场功夫，网上的教程和你手上的设备、光线、场景对不上；压缩到能跑，画质又被客户否

错误成本

审批不过项目延期，或交付画质不达标返工

现有替代

找有景区经验的外包队（报价不透明）

偶发部分可解证据中
高斯泼溅实景建模无人机航测空域审批景区VR
🖥 网站提供采集到上机的全流程成本测算器与翻车案例库；拍摄与现场调参必须到场
S08

客户一句「做个 VR 的」，报价怎么出

创意制作人
触发事件

客户微信丢来一句话需求，周五之前要报价，没有方案没有场景清单

当前做法

按往期项目拍工时 → 估资产量 → 加联调与售后 → 心里没底整体上浮两成 → 中不中标全凭手感

所需数据

需求描述、往期项目工时账、目标机型与场景数

决策参数

交互点数量、资产精度等级、平台数、现场部署天数、验收轮次

具体痛点

行业没有公开报价基准，同一个需求各家报价能差几倍；漏估一项（比如现场标定三天）毛利就没了

错误成本

低价中标即亏损，报高了直接丢单

现有替代

翻旧项目表格 + 私下问同行

周部分可解证据高
VR项目报价工时估算开发成本内容外包价格
🖥 匿名化项目报价档案（类型×资产量×机型×成交区间）+ 工时清单模板；最终报价要结合自家团队成本
S09

客户不戴头显，评审全靠脑补

创意制作人
触发事件

关键评审会上客户领导拒绝戴头显，要求「先看看效果」再决定是否继续

当前做法

录屏剪片 → 拼 PPT → 领导仍问「戴上去到底什么感觉」 → 凭想象提意见，改完还不是他要的

所需数据

录屏素材、分镜脚本、上一版被毙的原因记录

决策参数

镜头语言、节奏、交互点呈现方式

具体痛点

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 机型与方案选型：统一口径的头显实测库、大空间定位方案对比、各机型渲染性能基准
  • 报价与验收：匿名化项目报价档案、工时清单模板、可写进合同的验收条款与测试方法库
  • 内容目录与课标匹配：按学段/学科/教材版本结构化的 VR 内容目录，支持试看与核验
  • 情报与对标：公开中标记录聚合、同业票价与运营档案、政策专项申报导航
  • 资产与版权：素材库授权条款对比、门店与版权方的内容授权撮合目录
  • 现场知识沉淀：部署检查清单、干扰排查案例库、商用故障知识库

🚧 必须线下 / 网站只能辅助

  • 真机体验与舒适度：佩戴压脸、发热、晕动必须上人实测，隔着屏幕验证不了
  • 数字孪生数据接入：数据在内网，涉及安全审批与跨部门博弈，只能驻场推进
  • 现场标定与运维：大空间逐点标定、商场干扰排查、设备拆修都是到场才能干的活
  • 政企决策与商务关系：预算窗口、拍板与尾款谈判在会下完成，网站只能提供情报线索
  • IP 授权与内容交易：分成、独占与档期条款要面谈签约，适配实施依赖线下工程

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

内容团队带着「这个项目报多少钱、这个机型能不能跑」的问题来 → 查机型实测基准与报价区间 → 生成对比结论或估算单 → 回传自己的帧率实测与项目实绩 → 档案越厚报价越准，后来者依赖存量基准，形成回传惯性

需要建设的数据表
  • 头显机型库（参数/实测 PPD/重量/发热/连续佩戴记录）
  • 大空间方案库（定位方式/精度/并发/标定耗时/真实场地案例）
  • 项目报价档案（项目类型/资产量/机型/工时/成交区间，匿名化）
  • 内容目录库（题材/时长/适配机型/授权方式/分成模式/档期）
  • 公开中标与政策库（项目/金额/地区/专项/申报口径）
信任来源
  • 参数标注测量方法、机型固件版本与贡献者
  • 报价档案匿名化，只收可交叉核验的成交区间
  • 实测数据标注采集条件与日期，区分「自报」与「已复核」
  • 案例只收有公开出处的事实，附来源与时间
可做产品形态
XR 选型对比站（头显/定位方案/引擎的统一口径实测库 + 渲染基准）项目报价与验收工具站（工时模板 + 报价区间 + 验收条款生成器，可导出合同附件）VR 内容目录与版权撮合平台（门店 ↔ 版权方，按题材/档期/分成模式检索）招投标与政策情报站（公开中标聚合 + 专项资金与申报口径导航）行业经营对标库（LBE 门店票价/排片/换片节奏/存活年限的案例档案）

访谈与验证 痛点是假设，访谈才是裁决

访谈对象
VR 内容工作室创始人/制作人 3～5 人景区与商业体沉浸项目负责人 2～3 人大空间门店店长/运营 2 人工业数字孪生项目经理 2 人系统集成商投标与交付经理 2 人
验证指标
  • 单次机型/方案对比耗时：从 3～5 天缩到半天以内
  • 报价参考被实际签约项目引用的次数（目标：月 10+）
  • 实测数据回传条数（机型帧率/标定耗时/报价实绩，目标：200 条）
  • 付费验证：至少 3 家内容团队、门店或集成商为报价基准/内容目录/验收模板付费
访谈问题清单（12）
  1. 最近一个项目从需求到签约聊了几轮？报价改了几版，最后亏在哪一项？
  2. 你怎么判断一个机型能不能跑你的内容？有没有踩过参数虚标的坑？
  3. 客户验收用什么标准？有没有因为「效果不满意」被压过尾款，压了多少？
  4. 做过的项目里有没有客户第二年续费或更新内容的？靠什么促成的？
  5. 内容成本里最大的一块是什么？试过哪些降法（素材库/AI 生成/实景扫描），效果如何？
  6. 大空间项目现场标定与联调一般耗几天？最大的不确定性来自哪里？
  7. 教育采购的技术参数是谁写的？内容商怎么证明「与课标对齐」？
  8. 数字孪生项目里数据接入花了多少时间，卡在谁那里？最后是真数据还是示意动画？
  9. 门店换片时版权方要价与分成怎么谈？适配工作量谁承担？
  10. 如果有一个报价基准库/机型实测库，你愿意回传自己的数据换权限吗？什么条件？
  11. 找外包时怎么筛？有没有交付翻车的经历？
  12. 你现在每周花多少时间找资料、比参数？最希望哪个环节有一个网站？
