生物医药

产业链地图

上游原料 / 部件 / 设备

菌种与细胞工厂

出发菌株、底盘细胞、基因元件与编辑工具的开发、保藏与授权

高校院所、菌种保藏中心（如 CGMCC）、合成生物平台企业菌株权属链条分散在高校、保藏中心和平台公司，商用授权是放量前必过的坎
碳源与培养基原料

葡萄糖、糖蜜、甘油、玉米水解糖及氮源、维生素等培养基组分

玉米深加工与氨基酸企业、糖蜜贸易商原料占发酵成本大头，糖价波动直接打穿毛利
生物反应装备与仪表

发酵罐、连消系统、溶氧/尾气仪表、离心、膜分离与干燥设备

国产发酵装备厂、进口生物工艺设备商非标定制、没有公开的实机运行数据，选型基本靠口碑
检测与合规服务

菌种鉴定、批次检测、毒理试验与注册申报服务

第三方检测机构、注册代理、申报咨询公司新物质缺标准检测方法，同一指标各家口径不一

中游制造 / 集成 / 流通

菌株构建与筛选

基因编辑、定向进化、高通量筛选拿到目标表型菌株

合成生物学公司研发中心、高校课题组筛选在摇瓶和微孔板条件下做，与罐上环境天然脱节
发酵工艺开发与放大

从 5L 罐到百吨罐的工艺转移、补料策略与稳产

企业中试中心、发酵代工/CDMO 平台放大不是等比缩放而是重做一遍工艺，参数只能逐级实测
分离提取与精制

破壁、絮凝离心、膜滤、色谱、结晶与干燥

企业提取车间、分离纯化装备与耗材商提取成本常占一半左右，立项时最容易被低估的环节
成品化

原料级蛋白、单体的制剂化或聚合加工

生物基材料企业、原料药与食品配料工厂GMP 和食品级车间认证决定产品能进哪个市场

用户角色地图 谁在干活、被考核什么、卡在哪

菌株改造研发
是谁

在合成生物学/生物制造公司研发中心做菌株设计、基因编辑与筛选

被考核

滴度与得率提升幅度、菌株交付周期

用什么干活

CRISPR 编辑体系、摇瓶与微孔板、高通量筛选、文献与专利库

最常见卡点

摇瓶筛出的高产株一上罐就「变脸」，基因型和工艺的贡献拆不开

发酵工艺工程师
是谁

在发酵企业或中试平台负责工艺转移、补料策略与批次执行

被考核

批次成功率、单位体积产率、原料单耗

用什么干活

台式与中试发酵罐、DOE 软件、DCS/SCADA 曲线

最常见卡点

放大后溶氧和混合全变，参数逐罐重摸，每轮试错烧的是真原料

放大生产负责人
是谁

管万吨级产线的稳产、成本、安全与环保

被考核

染菌率与倒罐率、单位成本、安全环保零事故

用什么干活

DCS/MES、批记录、设备维保台账

最常见卡点

一次染菌倒罐几十万没了，菌渣处置的环保口径还在年年变

分离纯化工程师
是谁

负责发酵液后端的破壁、分离、色谱精制与干燥

被考核

总收率、纯度、溶剂与耗材单耗

用什么干活

离心机、膜系统、色谱柱、喷雾干燥塔

最常见卡点

破壁-除杂-精制是一串连环取舍，没有现成答案，成本黑洞常被立项时忽略

合规注册专员
是谁

在原料或品牌企业负责新食品原料、化妆品与药品资质申报

被考核

注册周期、一次通过率、多辖区合规覆盖

用什么干活

卫健委/NMPA/FDA/EFSA 公开数据库、申报模板

最常见卡点

审评进度不透明、工艺路线换了要重报，境外状态更难追

下游品牌采购
是谁

在食品、美妆、材料品牌负责功能性原料与生物基材料的寻源

被考核

供应稳定、质量事故为零、成本达标

用什么干活

1688、行业展会、供应商问卷、第三方检测

最常见卡点

「发酵法生产」的宣传无法核实，型别、浓度、工艺口径各说各话

产业投资机构
是谁

被考核

用什么干活

文献库、专利库、招股书、专家访谈

分不清文献滴度和量产成本之间隔着几道坎

S01

摇瓶 120 g/L 的高产株，5L 罐上只剩一半

菌株改造研发
触发事件

定向进化筛到一株产量翻倍的工程菌，按流程从摇瓶转 5L 台式罐验证

当前做法

摇瓶复筛三遍 → 上 5L 罐按老工艺跑 → 滴度掉到摇瓶一半 → 猜是溶氧或补料问题 → 换转速、补料速率逐个试，一轮 3～5 天

所需数据

摇瓶与罐的完整工艺记录（转速、装液量、接种量）、菌株生长曲线、摄氧率估算

决策参数

溶氧 DO、体积氧传递系数 kLa、补料速率、pH、菌体浓度与比生产速率

具体痛点

摇瓶氧传递与罐完全不同，摇瓶筛出的「高产」可能只是耐低氧假象；基因型和工艺耦合，单变量归因极难

错误成本

好菌株被误杀或带病上中试，放大阶段损失以月计

现有替代

凭老师傅经验设罐参数，或买微型平行罐跑小平行（设备贵、通量有限）

周必须线下证据高
摇瓶上罐溶氧滴度掉产放大效应kLa
⛔ 线下原因：氧传递与放大效应依赖本厂罐体几何与实测 kLa，别处的数据不可迁移——网站只能做「摇瓶-罐差异」的机理说明与排查清单
S02

3 立方到 100 立方，补料曲线全部重摸

发酵工艺工程师
触发事件

中试 3m³ 连续五批达标，公司决定直接上百吨罐试产

当前做法

按几何相似放大算罐压、搅拌、通气 → 第一批跑崩溶氧 → 手动降补料保菌活 → 一批一批修曲线，一批 5～7 天

所需数据

中试批次全参数记录、大罐设备说明书（桨型、功率、仪表量程）、物料衡算表

决策参数

单位体积功率、表观气速、溶氧、比生长速率控制、补料总量与时段分配

具体痛点

放大后混合时间和剪切环境大变，中试参数只是起点；每批试错烧的是几十吨培养基和一周工期

错误成本

试产延期一到两个季度，错过客户供货窗口

现有替代

请设备商工艺工程师驻场（经验限于其设备）+ 内部老经验口口相传

月必须线下证据高
发酵放大补料策略溶氧控制百吨罐工艺转移
⛔ 线下原因：放大参数必须在大罐上实测迭代，外部经验只能当起点——网站可收录公开的放大失败模式清单作参考
S03

连续三罐染菌，一罐倒掉几十万

放大生产负责人
触发事件

旺季满产时大罐连着三批染杂菌，只能整罐灭菌后倒掉

当前做法

倒罐清洗 → 逐项排查：种子液镜检、空气过滤器完整性、阀门法兰渗漏、消泡系统、灭菌曲线 → 找到根因前不敢复产 → 全线停产等待

所需数据

染菌批次时间线、染菌镜检照片、设备维保记录、灭菌与保压曲线

决策参数

染菌出现的世代时间点、污染菌种类别、灭菌 F0 值、过滤器完整性数据

具体痛点

染菌根因常是多个小漏洞叠加（一个垫圈加一次罐压波动），排查像破案；每倒一罐是几十万的原料加工费直接蒸发

错误成本

一罐废液几十万元起，停产一周影响全年交付

现有替代

老师傅「闻罐看罐」+ 事后加装在线染菌监测（投资大）

月必须线下证据高
发酵染菌倒罐空气过滤器灭菌F0排查
⛔ 线下原因：染菌排查依赖对本厂管路阀门的现场检查——网站只能沉淀行业通用的染菌故障树与案例复盘
S04

论文滴度 50 g/L，离万吨线还有几道坎

产业投资机构
触发事件

被推荐的合成生物学项目自称「滴度已达文献领先水平」，要求两个月内出投资意见

当前做法

查文献最高滴度 → 对照成熟品类（氨基酸、有机酸）的公开工业指标 → 访谈创始人 → 仍算不出吨级成本 → 写报告时主观折中

所需数据

项目自报滴度与得率、文献值、成熟品类的公开成本结构

决策参数

滴度 g/L、糖-产物得率、时空产率、提取收率、底物成本占比

具体痛点

实验室滴度不计提取收率与原料波动，时空产率和连续运行稳定性的公开数据极少；「克级」到「万吨级」之间没有公认换算标尺

错误成本

高估成熟度投出放不大的项目，或把真能落地的团队错杀

现有替代

每单花数万元请技术尽调 + 熟人专家电话

月部分可解证据中
合成生物学投资滴度时空产率技术尽调放大
🖥 网站建「品类×路线×规模」的公开指标对标库与放大距离评估清单；最终判断仍需实地看产线数据
S05

三家都叫重组胶原蛋白，型别浓度口径全不同

下游品牌采购
触发事件

功效护肤品新品立项，市场部点名用重组胶原蛋白，找到三家报价差一倍的供应商

当前做法

收三方规格书 → 发现型别（I/III 型）、分子量、浓度标注口径各异 → 追问检测方法 → 对方各说各话 → 只好自费送检

所需数据

三方规格书与检测报告、已发布的重组胶原蛋白行业标准、样品

决策参数

型别与序列一致性、纯度、内毒素、实际蛋白含量、终端配方稳定性

具体痛点

「重组胶原蛋白含量」没有统一测法，有的报总氮、有的报特征肽；宣传值和实测值能差出一截，踩坑成本由品牌兜底

错误成本

添加量不足等于宣传违规，产品被投诉下架

现有替代

只认大厂 + 每批自费送第三方检测（数万元/次）

月网站可解证据中
重组胶原蛋白原料甄别检测方法规格书供应商对比
🖥 原料甄别档案：按「指标×检测方法×标准依据」归一各家规格书，公示检测报告出处，收录常见宣传话术与实测差异案例
S06

竞品 HMO 已上市，我们的原料还卡在申报

合规注册专员
触发事件

品牌要上新一款含母乳低聚糖（HMO）的营养品，法务要求先确认原料合规状态

当前做法

查卫健委新食品原料公告与终止审评目录 → 查竞品用的是哪家的原料 → 追问供应商资质 → 口径拿不准就发函咨询 → 一轮下来数周

所需数据

新食品原料与扩大使用范围申报目录、供应商资质文件、竞品标签信息

决策参数

原料是否已获批或在审、使用范围与限量、自报还是代理报、工艺路线是否与获批一致

具体痛点

审评进度不公开、口径不透明；同一物质「发酵法生产」与「天然提取」按不同原料对待，路线换了要重新评估

错误成本

新品上市推迟半年起，或违规添加被通报

现有替代

请注册代理机构（单项目数万元起，口径偏保守）

季网站可解证据中
新食品原料HMO母乳低聚糖申报卫健委
🖥 合规状态追踪站：按「物质×工艺路线×辖区」整理已批准/在审/终止名单与时间线，关联供应商持有资质
S07

葡萄糖涨价，改糖蜜还是改甘油

发酵工艺工程师
触发事件

玉米糖价格上行或供应紧张，老板要求评估替代碳源把单位成本压回去

当前做法

查文献和同行用法 → 小试换碳源（糖蜜/甘油/水解糖）→ 杂质与抑制物拖慢生长 → 重新优化补料与氮源 → 逐级放大验证，前后一到两个月

所需数据

各碳源到厂价与供应稳定性、杂质谱（糖蜜灰分、甘油来源）、现有工艺窗口

决策参数

糖-产物得率变化、发酵周期延长、培养基成本、产物分离难度变化

具体痛点

替代碳源的批间杂质波动会传导到染菌风险和提取负荷，账面省的原料钱可能被发酵周期和提取成本吃回去

错误成本

切换失败浪费两个月工时，仓促切换导致批次合格率下滑

现有替代

只做小比例掺混 + 等糖价回落（被动挨打）

季部分可解证据中
替代碳源糖蜜甘油发酵原料成本培养基
🖥 网站做碳源换算工具（当量糖价与得率折算）和公开替代案例库；验证试验必须本厂做
S08

万吨线设备清单，设备商都说自己行

放大生产负责人
触发事件

董事会批了产线投资，要求三个月内定型发酵罐、连消、膜分离与干燥设备清单

当前做法

收 3～5 家设备商方案 → 各家推荐配置不同 → 要参照项目名单 → 现场看机 → 缺真实运行数据（染菌率、检维修频次），只能比价格和材质

所需数据

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 指标对标库：把文献、专利、招股书里的滴度、得率、时空产率按规模量级归一，让「我们到哪一步了」有据可答
  • 品类成熟度地图：按合规状态、成本临界点、产能落地给品类排期，回答「哪个品类先跑通」
  • 原料甄别与统一口径比价：供应商规格书按「指标×检测方法×标准依据」归一，宣传值与实测差异档案化
  • 多辖区合规追踪：新食品原料、化妆品原料与 GRAS/Novel Food 状态一站聚合
  • 中试与代工产能地图：罐体规格、无菌等级、保密条件结构化挂牌撮合
  • 染菌与放大故障知识库：通用故障树、排查清单与公开案例复盘，辅助车间决策

🚧 必须线下 / 网站只能辅助

  • 放大试错：摇瓶-中试-万吨线的参数依赖本厂罐体几何与菌株特性，只能逐级实测，外部数据不可迁移
  • 染菌排查与倒罐处置：现场检查阀门、过滤器与灭菌曲线，责任和决策都在车间
  • 提取纯化开发：破壁与色谱路线由产物分子特性决定，必须实验迭代
  • 种子批与菌种稳定性管理：传代、留样、复测是物理操作加台账体系
  • 验厂与信任建立：采购锁量、投资终判都要现场数罐、翻批记录
  • 环保与安全现场落实：菌渣处置审批、消防与职业健康核查在线下完成

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

用户带着「这个品做到什么水平、这家产能能不能用、这个证批到哪了」来 → 查对标库、产能档案与合规状态 → 拿走带出处的对比结论 → 回传自家脱敏批次数据或申报进度 → 覆盖品类越多对标越准，后来者依赖存量档案

需要建设的数据表
  • 品类指标对标库（产品/工艺路线/滴度/得率/时空产率/规模量级/出处）
  • 供应商与产能档案（罐容/无菌等级/投产状态/代工关系/履约记录）
  • 合规状态库（物质/工艺路线/辖区/状态/时间线/官方文件）
  • 专利与菌株授权库（序列家族/权利要求要点/法律状态/权利人）
  • 故障知识库（故障模式/征兆/排查步骤/案例出处）
信任来源
  • 每条指标标注出处（文献 DOI/专利号/招股书章节）与规模量级（摇瓶/罐/产线）
  • 数据分「文献值/企业自报/独立核验」三档标色，不混排
  • 合规状态只引用官方数据库条目并附查询日期
  • 无出处的成本数字不收录，区间估算标明假设

访谈与验证 痛点是假设，访谈才是裁决

访谈对象
合成生物学公司发酵工艺负责人 3～5 人万吨线放大生产与染菌防治一线工程师、班长 2～3 人功能食品与美妆品牌的原料采购 2～3 人生物制造赛道投资人 2 人新食品原料与化妆品注册顾问 1～2 人
验证指标
  • 对标查询被用于立项/尽调/采购决策的引用次数（目标：月 30+）
  • 单次技术水平判断从「熟人电话+现查文献」到出对标报告的耗时降到 1 天内
  • 产能档案促成采购与供给方首次接触的对数（目标：季度 10+）
  • 付费验证：至少 3 家企业为对标报告/合规追踪/产能撮合付费
访谈问题清单（12）
  1. 最近一次摇瓶高产株上罐掉产是什么产品？花多久找到原因？
  2. 你判断一个菌株「能不能放大」看哪几个指标？文献滴度你心里打几折？
  3. 染菌事故最常见的三个根因是什么？一次排查平均几天、损失多少？
  4. 找中试罐和代工产能现在靠什么渠道？信息里最缺哪几项？
  5. 采购功能性原料时，供应商宣传里你最不信的字段是什么？踩过什么坑？
  6. 新食品原料申报最耗时的环节是哪一步？审批进度从哪里查得到？
  7. 出口的 GRAS/Novel Food 状态你们怎么追踪？有没有漏判过？
  8. 自家滴度与行业水平的差距，你们靠什么方式知道？多久更新一次？
  9. 尽调时怎么核实企业自报的产量和成本？有没有被数据坑过？
  10. 出发菌株和底盘细胞的授权怎么谈的？权属上最大的坑是什么？
  11. 如果有对标库，你愿意贡献什么脱敏数据？想换回什么？
  12. 提取环节成本占比你心里有数吗？最头疼的耗材或工序是哪个？
