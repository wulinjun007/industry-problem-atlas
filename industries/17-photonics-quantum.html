光子与量子技术

电子信息

核心问题光子技术从实验室到产线的工程化缺口在哪，哪些元件国产化已就绪

这个产业赚「把光变成生产工具」的钱：激光器厂、光学元件厂、光模块厂在干活，事卡在高端光芯片/晶体/仪器还捏在海外手里、装调与工艺参数全靠老师傅手工攒；量子部分还在拿科研经费和示范工程养未来。

细分方向激光器光学元件光通信光子传感量子信息
典型用户光学工程师激光设备集成商科研平台光通信厂商前沿技术投资
重庆锚点上海交大重庆人工智能研究院发布量子科学计算平台「UnitaryLab 1.0」（公开报道口径），重庆以科研合作切入量子算力马上消费与重庆邮电大学共建量子重点实验室，面向金融场景探索量子算法应用（公开信息）北碚舟苏光电等本地光电企业起步；重庆光子制造配套尚薄，激光器与光模块龙头集中在武汉、深圳、苏州等地2026 年 2 月重庆发布量子科技「揭榜挂帅」3 方向 17 项任务，前沿项目以政府榜单方式组织攻关

产业核心用激光器、精密光学元件和光通信器件把「光」做成工业品；激光与光通信已大规模商用，量子信息以科研仪器和示范工程为前沿延伸。

用户角色地图 谁在干活、被考核什么、卡在哪

光学工程师
是谁

在激光器/光学仪器/光模块公司负责光路设计、元件选型与整机装调

被考核

光学指标达成率（MTF/波前/损耗）、打样与装调良率

用什么干活

Zemax/CodeV、干涉仪、光具座、供应商规格书

最常见卡点

设计完美一装调就掉指标；小批量定制件贵、慢、报价口径乱

激光器研发工程师
是谁

在激光器厂商研发光纤/固体/超快激光器

被考核

功率与光束质量达标、寿命与可靠性、BOM 成本

用什么干活

功率计、光束质量分析仪、光谱仪、老化台架

最常见卡点

高功率下模式不稳定、热管理难题、国产核心件验证周期长

光模块测试工程师
是谁

在光模块厂负责耦合、高速电光测试与失效分析

被考核

测试良率与通量、误码/眼图指标

用什么干活

采样示波器、误码仪、耦合台、温箱

最常见卡点

仪器机时排队，来料波动与工艺漂移混在一起难定根因

光通信采购工程师
是谁

在光模块/光器件厂采购光芯片、无源器件与结构件

被考核

供应保障、来料不良率、采购成本

用什么干活

BOM、询价表、IQC 报告、原厂配额函

最常见卡点

高端芯片缺货涨价受制于人，国产件批次一致性没人担保

激光设备集成工程师
是谁

在集成商/整机厂把激光器配成切割焊接清洗设备并交付工艺

被考核

试切通过率、交付周期、售后成本

用什么干活

试切工作台、显微镜、自建参数 Excel

最常见卡点

工艺参数盲试、激光器品牌口碑靠打听、安全合规自己造轮子

科研平台管理员
是谁

在高校/研究所大型仪器平台管采购、机时与维修

被考核

用什么干活

招投标文件、机时预约系统、报修工单

报价不透明交期长，一个备件卡死全平台，参数口径对不上没法比选

器件销售/BD工程师
是谁

在光器件/激光器厂负责开拓终端大客户与渠道

被考核

制造企业工艺主管
是谁

被考核

用什么干活

试产报告、第三方检测、设备商打样

最常见卡点

前沿技术投资人
是谁

在基金/政府平台评估光子与量子项目

被考核

真实工作场景 每张卡片：什么触发 → 现在怎么做 → 卡在哪 → 值不值得数字化

S01

小批量定制镜片打样，报价比三家差一倍

光学工程师
触发事件

新品光路定型，需要 20 片定制窗口片/透镜（材质、口径、面形、镀膜均非标），首版只打样几十片

当前做法

翻展会名片和黄页 → 给 4～6 家光学厂发规格书询价 → 报价差一倍且交期从 2 周到 8 周不等 → 打电话逐家确认对方是否真理解了面形与镀膜要求

所需数据

图纸与规格书（材质/口径/中心厚/面形 PV 或 RMS/镀膜光谱）、各厂报价单

决策参数

面形精度（λ/10 还是 λ/4）、镀膜透过率与附着牢度、划痕瑕疵等级、起订量、打样周期

具体痛点

同一张图 A 家说一周交货 B 家要开模六周；规格书写 λ/10 有人按 λ/4 报价，装到整机才发现口径理解错了

错误成本

打样返工一轮 2～6 周，整机联调节点整体后移

现有替代

展会名片加熟人介绍，微信里逐家追问；急件加价买海外现货但要迁就改设计

周网站可解证据高
定制镜片光学镀膜打样周期面形精度透镜报价
🖥 结构化询价：填规格自动匹配能做的厂商 + 报价/交期/起订量同口径对比 + 规格书写法检查（防口径歧义）
S02

非线性晶体采购：损伤阈值口径对不上

光学工程师
触发事件

倍频/参量振荡光路需要 BBO 或 LBO 晶体，切割角按具体波长定制，还要评估皮秒脉冲下的损伤阈值

当前做法

找两三家晶体厂询价 → 各家给的损伤阈值测试条件不同（纳秒/皮秒、1064/532nm）→ 按经验换算 → 到货上机才知行不行

所需数据

波长、脉宽、重复频率、光斑尺寸、切割角要求、各厂数据表

决策参数

切割角公差、通光孔径、平行度、损伤阈值（J/cm² @ 条件）、配套镀膜、交期（常 8～16 周）

具体痛点

损伤阈值没有统一测试条件口径，手册数字没法直接比；订错切割角整块晶体报废，一枚数千到数万元

错误成本

晶体报废另加重订 8 周以上，实验或产品进度停摆

现有替代

锁死一家老供应商（贵但稳）；或买现货通用切割角自己迁就光路

月网站可解证据高
BBO晶体LBO损伤阈值倍频非线性晶体
🖥 晶体参数库把各家阈值归一到「J/cm² @ 脉宽×波长×重频」统一口径 + 切割角换算工具 + 交期实况
S03

整机装调完 MTF 不达标，查不出公差链哪一环爆了

光学工程师
触发事件

镜头/模组样机装配后实测 MTF 比设计值低两成，波前差超标，距客户评审只剩两周

当前做法

按灵敏度表逐项排查（间隔/偏心/倾斜）→ 干涉仪测单件 → 拆装重调 → 凭手感收紧最敏感的公差

所需数据

设计公差分配表、各元件实测面形/厚度数据、干涉仪与 MTF 台数据

决策参数

灵敏度系数、元件实测偏差方向、装配应力、温度漂移

具体痛点

设计软件的公差分析假设元件理想，实际是加工偏差、装配应力、镀膜厚度叠加；排查靠工程师个人手艺，每人一套经验

错误成本

样机节点延误，客户端评审推迟甚至丢单

现有替代

老师傅带教加反复试装；蒙特卡洛公差仿真在软件里重跑

周必须线下证据中
公差分析波前差MTF测试光学装调干涉仪
⛔ 线下原因：装调是台架上的手艺活，偏差来自实物叠加——网站只能沉淀公差分配案例库与排查清单
S04

千瓦级光纤激光器高功率下模式不稳定（TMI）

激光器研发工程师
触发事件

3kW 样机升到额定功率十几分钟后光束质量恶化、功率波动，客户现场验收前两周

当前做法

排查弯曲直径/剥模器/光纤长度/泵浦亮度 → 换光纤批次重绕 → 每轮试验几小时到一天，变量排不完

所需数据

光纤参数（模场直径/吸收系数）、泵浦源光谱、绕纤直径、水冷温度记录

决策参数

模场面积、弯曲损耗、热负载、泵浦光谱漂移、卷绕方式

具体痛点

TMI 机理文献只给定性结论，触发阈值与本机卷绕、涂层、熔接点质量强相关；公开资料给不出你这一台机器的解

错误成本

验收失败丢单，一轮设计迭代 3～6 个月

现有替代

抄同行卷绕参数，自建内部门限，全靠试错堆时间

周必须线下证据高
模式不稳定TMI光纤激光器光束质量高功率
⛔ 线下原因：阈值取决于本机光纤/泵浦/热设计的实测——网站只能做公开研究综述与排查清单
S05

国产泵浦源替代进口的验证拉锯

激光器研发工程师
触发事件

进口泵浦芯片涨价缺货，采购要求半年内导入国产替代，研发负责验证背书

当前做法

要国产件 datasheet → 上机对比电光效率/波长漂移 → 自己排期做加速老化 → 出对比报告给领导拍板

所需数据

进口件基准数据、国产件数据表、老化台架、实际工况谱

决策参数

电光效率、波长温漂、亮度、千小时老化衰减、批次一致性

具体痛点

国产厂数据表只给典型值，不给分布和老化曲线；验证周期 3～6 个月，任何一台在客户现场失效就前功尽弃

错误成本

替代失败退回进口件，成本与交期双重受制

现有替代

小批量上机试用加驻厂盯产，靠时间换信任

月部分可解证据中
泵浦源国产替代激光二极管有源光纤加速老化
🖥 网站做「进口↔国产」型号对照与各家公开验证状态、用户反馈档案；老化实测仍要自己做
S06

飞秒激光器立项：压缩光栅等核心件寻源

激光器研发工程师
触发事件

公司立项工业级飞秒激光器，BOM 里脉冲压缩光栅、可饱和吸收体（SESAM）等核心件国内能做的没几家

当前做法

翻论文与展会名录找供应商 → 发邮件询价 → 海外交期以年计且有出口管制风险 → 国内样品指标待上机验证

所需数据

目标脉宽/能量/重频、光栅尺寸与衍射效率要求、供应商样品数据

决策参数

衍射效率、损伤阈值、色散一致性、交期、两用物项管制风险

具体痛点

超快核心元件全球就几家，公开渠道查不到真实交期与良率；管制清单一变，立项可行性就要重算

错误成本

核心件断供，整机立项直接搁置

现有替代

依赖代理商口头承诺，立项时赌交期

偶发部分可解证据中

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 元件选型与打样比价：镜片/晶体/无源器件的参数库，把面形精度、镀膜、损伤阈值归一到统一口径
  • 激光器与仪器选型器：按材料/厚度/脉宽/功率出候选清单，标注测试条件、交期与国产替代对照
  • 国产替代追踪：光芯片/泵浦源/有源光纤的国产型号—验证状态—用户反馈档案
  • 高端仪器情报：科研采购最痛的报价区间、真实交期、维修渠道与备件货期档案
  • 展会与竞品情报的结构化沉淀：CIOE、慕尼黑光博会新品与价格口径按厂商归档、逐年可比
  • 政策与揭榜挂帅导航：量子/光子榜单任务、申报口径与公开进展跟踪

🚧 必须线下 / 网站只能辅助

  • 光机装调与耦合对准：依赖台架实操与手艺积累，网站只能给公差分析参考与失效案例
  • 激光工艺参数调试：参数随本机与材料炉号漂移，试切必须在线下做，网站只能给初值参考
  • 高功率器件与车规可靠性验证：老化、温循、寿命试验必须物理进行
  • 现场安全合规与工程施工：激光安全改造、光纤传感布线、试产验收都发生在线下
  • 大客户认证稽核与信任建立：现场审核、送样驻场无法在线替代
  • 高端仪器维修：依赖原厂工程师到场与海外备件物流

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

集成商/科研平台带着「这个件哪家能做、这台激光器/仪器值不值」来 → 查参数库与国产替代对照 → 生成统一口径的询价单与初筛结论 → 回传打样实测与使用反馈 → 档案越厚，后来者越依赖

需要建设的数据表
  • 光学元件参数库（类型/材质/面形精度/镀膜/损伤阈值/起订量/打样周期）
  • 激光器型号库（功率/脉宽/M²/波长/厂商/测试条件/交期/维修口碑）
  • 国产替代对照库（进口型号↔国产型号/验证状态/差距备注）
  • 高端仪器档案（型号/配置/报价区间/交期/维修渠道/备件货期）
  • 工艺参数案例库（材料/厚度/激光器型号/参数/质量结果，脱敏回传）
信任来源
  • 每个参数标注来源：原厂 datasheet 原文引用加版本日期
  • 打样实测数据标注提供方与测试条件，自报与核验分色区分
  • 激光器口碑只收可交叉验证的维修/故障记录
  • 量子进展档案只收有出处的事实，逐条标注公开来源与日期
可做产品形态
光学元件参数库 + 打样询价比价站（面形/镀膜/损伤阈值统一口径）激光器/工艺选型器（材料×厚度×质量要求 → 设备候选与参数初值）国产替代器件追踪档案库（进口↔国产型号对照 + 验证状态 + 交期）高端仪器情报平台（科研采购版：报价区间/交期/维修/兼容性矩阵）光子与量子项目成熟度尽调证据清单（面向投资人与揭榜挂帅评审）
