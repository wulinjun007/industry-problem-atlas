02

AI及机器人

智能装备

核心问题哪些自动化改造真正算得过账（投资回收期），集成商的交付瓶颈卡在哪

这个产业赚「卖机器人+把机器人调进产线」的钱；本体厂打价格战、数千家集成商的驻场工程师在干活，事卡在改造的账算不清、非标交付全压在现场调试环节。

细分方向工业机器人协作机器人人形机器人机器视觉具身智能
典型用户系统集成商终端工厂自动化工程师机器人本体厂商视觉算法工程师产业投资机构
重庆锚点重庆 AI 及机器人 2025 年全产业链产值 420 亿元（+14%），整机市场超 100 亿元，产业链完整度超 68%（重庆产业地图口径）宇树（重庆宇羿落地大渡口）、银河通用（璧山）等整机项目布局重庆，承载区为大渡口/璧山/两江/西部科学城；官方口径短板：减速器、灵巧手等核心零部件本地配套待补重庆以智能网联新能源汽车为第一大产业集群（长安、赛力斯为链主），整车与零部件产线的自动化改造需求为本地集成商提供主场场景重庆是全球主要笔电生产基地之一，3C 产线的装配、锁附与检测环节为协作机器人和机器视觉提供密集应用（公开产业事实）

产业核心用工业机器人、协作机器人、人形机器人与机器视觉替代产线上的重复体力劳动，AI（视觉引导、具身智能）是使能技术；本体厂造硬件、集成商把工艺落地到产线，赚「设备+交付」的钱。

产业链地图

上游原料 / 部件 / 设备

精密减速器/伺服/控制器

RV与谐波减速器、伺服电机与驱动、控制器，机器人的三大核心零部件

纳博特斯克、哈默纳科、绿的谐波、双环传动、汇川技术等占本体成本大头；高端减速器与控制器的可靠性记录仍以日欧系为标杆，人形机器人带动行星滚柱丝杠等新品类
传感器与末端执行器

六维力/力矩传感器、编码器、触觉传感器、气动夹爪与灵巧手

ATI、坤维科技、Robotiq、兆威机电等灵巧手与触觉传感器是人形机器人新卡位，寿命与一致性尚无公认标准，参数要靠买方自建台架验证
机器视觉部件

工业相机、镜头、光源、3D相机

基恩士、康耐视、海康机器人、奥普特、梅卡曼德等3D相机价格近年快速下探，但反光曲面件等难案的光学方案适配仍靠集成商试错
结构件与传动基础件

铝合金/镁合金结构件、铸件、丝杠导轨、线束

各地机加工与直线传动厂商人形机器人轻量化把镁合金、PEEK等新结构材料推上台面，中小加工厂工艺水平参差

中游制造 / 集成 / 流通

机器人本体制造

六轴/SCARA/DELTA工业机器人、协作机器人、人形与四足机器人整机

发那科、ABB、安川、库卡；埃斯顿、埃夫特、节卡、遨博；宇树、优必选、智元、傅利叶等工业本体价格战激烈、毛利薄；人形机器人尚在从演示走向订单验证，量产一致性与成本是坎
系统集成

工艺方案、非标设计、安装调试、交钥匙交付

数千家区域集成商，汽车/3C/锂电各有专业队伍非标定制、垫资、账期长、依赖驻场工程师，是产业链最苦也最就业的一环，交付能力决定项目生死
机器视觉系统集成

检测/引导/测量方案落地：打光、采图、算法与现场部署

视觉集成商、本体厂商视觉部门POC通过不等于产线稳定，缺陷样本与反光件是绕不开的坎
机器人软件与工具链

离线编程、节拍仿真、多机调度（RCS/FMS）、控制器二次开发生态

本体厂软件部门、独立软件商、ROS/Isaac等开源生态各品牌编程语言与指令体系不互通，换品牌要重学；工业级仿真license贵、建模工作量大

下游应用 / 服务 / 终端

汽车及零部件

焊装/涂装/总装、机加工上下料、装配与检测

整车厂及其各级零部件供应商传统最大应用行业、标准最高；改造窗口跟着新车项目走，验收条款最较真
3C电子

精密装配、锁附、点胶、检测、打磨

消费电子代工厂换代快、柔性要求高，是协作机器人与视觉检测的主要产地
一般工业与新能源

金属加工、锂电、光伏、家电、食品的搬运/码垛/包装

各行业工厂改造意识参差，算账最较真——回收期算不清就不立项
物流仓储

AGV/AMR搬运、拆码垛、分拣

电商物流、制造业仓配机器人与视觉融合最深的新增场景，按件计价的账相对好算
具身智能新场景

人形/四足机器人在工厂实训、巡检、商业展示与科研

车企工厂、高校院所、展馆文旅买单方尚未定型，多数订单带科研示范性质，「演示可用」与「产线可用」之间隔着数量级

用户角色地图 谁在干活、被考核什么、卡在哪

系统集成商方案工程师
是谁

在集成商负责售前：工艺分析、选型、布局仿真、方案报价

被考核

方案中标率、报价偏差、方案毛利

用什么干活

CAD、离线编程仿真软件、Excel测算表、各家样本册

最常见卡点

非标项目没有公开价格基准，报高丢单报低亏本；客户一句话需求，方案却要两周

系统集成商调试工程师
是谁

在集成商负责现场安装、示教编程、试运行与验收配合

被考核

按期终验、驻场人天、一次验收通过率

用什么干活

示教器、PLC与机器人编程软件、万用表、调试记录表

最常见卡点

来料公差和安装基面问题全部到现场才爆发，驻场时间常超预算一倍，人被钉在客户产线上

系统集成商销售
是谁

在中小集成商负责找项目、投标与回款，往往老板亲自兼

被考核

签约额、回款率、现金流

用什么干活

人脉圈、招投标网站、展会名录

最常见卡点

改造需求很少公开招标、全靠关系获客；3331付款节奏下垫资压力全在自己身上

终端工厂自动化工程师
是谁

在汽车零部件/3C/一般工业工厂负责自动化立项、选集成商、验收与改造管理

被考核

项目按预算按期交付、投产后节拍良率达标

用什么干活

Excel测算表、招标文件、CAD布局图、生产报表

最常见卡点

回收期要给老板算明白，但人工全成本与隐性收益没人给统一口径；验收标准写粗了被集成商钻空子

设备维护技师
是谁

在终端工厂负责机器人工作站的日常点检、保养与故障处理

被考核

停机时长、备件费用、保养计划达成率

用什么干活

报警手册、品牌专用调试软件、备件台账

最常见卡点

过保后集成商响应慢，各品牌报警代码互不相通，处置经验全在老师傅脑子里

机器人本体厂商应用工程师
是谁

在机器人厂商负责行业工艺开发、大客户技术支持与竞品跟踪

被考核

行业方案复用率、客户项目成功率

用什么干活

自家控制器、样机、项目调试记录、展会资料

最常见卡点

工艺knowhow散落在各个项目里难沉淀成标准行业包；核心零部件交期波动直接打乱交付

人形机器人研发工程师
是谁

在机器人公司负责关节模组/灵巧手选型、整机集成与具身智能训练数据

被考核

样机迭代周期、任务成功率、整机成本

用什么干活

SolidWorks、URDF/Isaac仿真、遥操作平台、示波器

最常见卡点

新兴零部件参数虚标只能自建台架验证；真机数据采集靠人肉遥操作，成本高到难规模化

视觉算法工程师
是谁

在视觉公司/集成商负责检测与引导方案：打光、采图、算法与现场部署

被考核

过杀率/漏检率、POC通过率、现场稳定运行时长

用什么干活

Halcon/VisionPro/自研SDK、光源相机台架、Python

最常见卡点

反光件打光要试错几十轮；缺陷样本凑不齐，客户验收口径在漏检与过杀之间摇摆

产业投资/研究员
是谁

在基金/券商/政府平台评估机器人项目与人形机器人赛道

被考核

判断准确率、报告被引用数

用什么干活

IFR/GGII数据、发布会视频、招投标公告、访谈纪要

最常见卡点

发布会Demo与可靠连续作业差一个数量级，公开信息拼不出中立的成熟度证据链

S01

给老板算一台机器人的投资回收期

终端工厂自动化工程师
触发事件

车间数控机床上下料想换成机器人，总经理要求「几年回本，算清楚再来立项」

当前做法

找集成商要报价 → Excel列设备款/安装费/人工工资 → 算出回收期 → 老板拿隔壁厂更低的报价来砍价

所需数据

设备报价、人工工资与社保口径、产线节拍、现用工人数、折旧年限

决策参数

人工全成本系数（含社保公积金约为工资一倍多）、班次人数、良率与工伤隐含成本、维保费、停产改造损失

具体痛点

人工成本口径各家算法不同，招工难、工伤、管理这类隐性收益没法量化；两家集成商给出的回收期相差一倍，老板反而更不敢拍板

错误成本

算错账要么错误立项几十万打水漂，要么错过改造窗口产能接不上

现有替代

让集成商代算（天然往有利方向算）+ 老板拍脑袋

月网站可解证据中
自动化改造投资回收期机器人ROI机器换人人工成本
🖥 回收期计算器：公开全部假设参数（人工全成本系数/折旧/维保）供修改，配同行业同工位公开案例的回收期区间对照
S02

两周内出一份非标集成方案报价

系统集成商方案工程师
触发事件

终端客户发来一段现场视频和一句话需求（「这道工序想上机器人」），要求两周内给方案和价格

当前做法

看视频估工况 → 查各家样本选型号 → 凭同类项目经验估工作量 → 报一个自己心里打鼓的价

所需数据

工件图纸或实物、节拍要求、现场布局照片、客户预算区间

决策参数

机器人负载/臂展/防护等级、夹具方案、安全围栏、PLC与调试工时、毛利率底线

具体痛点

非标方案没有公开价格基准，同类项目价差能到一半；报低了自己亏、报高了丢单，全凭经验赌

错误成本

报价失误直接吃掉整个项目利润甚至倒亏

现有替代

翻自家历史报价表 + 套同行的模糊口风

周部分可解证据中
系统集成报价非标自动化机器人选型方案设计投标报价
🖥 网站可建「工位类型×设备清单×工时区间」的报价参照库与方案模板；最终报价仍要结合自家成本结构
S03

来料公差超标，调试现场返工

系统集成商调试工程师
触发事件

设备进场后发现来料件位置散布远超方案假设，抓取频繁失败，客户验收盘不下来

当前做法

现场加视觉引导或改夹具 → 改程序重调 → 补签技术协议扯费用 → 驻场时间翻倍

所需数据

现场实测来料位置数据、抓取失败记录、合同技术附件

决策参数

定位精度需求、夹具冗余设计、补视觉方案的成本、双方责任划分

具体痛点

方案阶段假设的来料公差没人核实，问题全部集中到驻场阶段爆发；补签协议谈判旷日持久，项目利润被驻场人天吃光

错误成本

驻场超期一到两个月，单项目利润归零甚至亏损

现有替代

派老师傅坐镇 + 合同写「以现场实测为准」（客户不认）

周必须线下证据高
现场调试来料公差视觉引导返工驻场
⛔ 线下原因：公差、安装基面、来料状态只有到场实测才知道——网站只能沉淀「方案阶段勘场检查清单」让后来者少踩坑
S04

四大家族还是国产：品牌选型对决

终端工厂自动化工程师
触发事件

立项报告要定品牌，老板问「国产便宜三成，你敢不敢用、坏了谁负责」

当前做法

下载各家样本对比负载曲线和重复定位精度 → 找用过的人打听故障率 → 让两家分别出方案再比

所需数据

各品牌样本册、同行业应用案例、本地售后网点分布

决策参数

负载-臂展工作区间、防护等级、故障率口碑、本地响应时效、备件价格、与现有产线对接成熟度

具体痛点

样本参数测试条件写法不一（重复定位精度很少标注完整ISO 9283口径），真实故障率只有圈内口头评价；国产与合资的差距随代际变化，手上的信息总是滞后

错误成本

选错品牌，五到八年生命周期里停机与维保的代价远超当初省下的差价

现有替代

展会看样机 + 参观熟人工厂

季部分可解证据中
机器人选型四大家族国产机器人负载臂展重复定位精度
🖥 网站做统一口径的型号参数库（标注测试条件与样本版本）+ 按行业的真实用户评价；拍板前仍要试机与实地考察
S05

反光金属件的视觉检测POC

视觉算法工程师
触发事件

客户寄来一批抛光后的机加工件，要求两周内证明「划痕和磕碰能检出来才谈合同」

当前做法

搭光源相机台架 → 同轴光/穹顶光/低角度光轮着试 → 采图写算法 → 出POC报告

所需数据

样件、缺陷判定标准样照、客户节拍与精度要求

决策参数

打光角度与波长、成像对比度、过杀率/漏检率、单件处理耗时

具体痛点

反光曲面上「缺陷」和「反光」在图像里长得一样，光源方案试错几十轮是常态；POC用的是干净样件、产线来料带油污铁屑，POC通过不等于产线稳定

错误成本

POC失败丢单；POC过了产线不稳，验收扯皮收不回尾款

现有替代

请光源原厂FAE支援 + 借同行案例的打光方案

周必须线下证据高
机器视觉反光检测光源选型POC划痕检测
⛔ 线下原因：打光与成像必须对着实物反复试——网站只能沉淀「材质×缺陷类型×光源方案」的案例库供预筛方向
S06

人形机器人关节模组选型与验证

人形机器人研发工程师
触发事件

新一代样机启动，腿部关节要在谐波减速器与行星滚柱丝杠（线性关节）之间定案

当前做法

收集供应商样本 → 要样品上自建台架 → 跑扭矩密度/背隙/效率/寿命测试 → 数据出来方案早该冻结了

所需数据

供应商datasheet、样件、自建测试台架

决策参数

扭矩密度、背隙、效率曲线、额定寿命、批量价格、供货稳定性

具体痛点

新兴供应商样机参数好看，但批量一致性与寿命没人背书，datasheet不敢直接采信；寿命测试一轮数月，直接卡住样机迭代节奏

错误成本

选错方案一代样机报废，迭代拖半年以上，融资演示跟着延期

现有替代

圈内朋友推荐 + 小批量先试

季部分可解证据中
关节模组谐波减速器行星滚柱丝杠扭矩密度人形机器人
🖥 网站可汇总零部件参数（区分自报/第三方实测）与台架测试方法模板；寿命与一致性验证必须自己做
S07

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 算账环节：自动化改造回收期计算器，统一人工全成本/折旧/维保口径，配同工位行业案例区间对照
  • 选型环节：机器人/零部件/视觉方案参数库，统一标注测试条件与样本版本，国产与合资同台对比
  • 交付环节：验收条款模板、勘场检查清单、标讯倾向性分析等集成商工具箱
  • 运维环节：品牌×型号×报警代码的故障知识库与备件渠道索引
  • 撮合环节：工厂改造意向与集成商能力档案的双向登记，成单前先看清对方底细

🚧 必须线下 / 网站只能辅助

  • 现场调试与验收：来料公差、安装基面、联调问题只能到场解决，驻场是集成商的成本黑洞也是交付瓶颈本体
  • 视觉打光与缺陷采图：光学方案必须对着实物反复试，POC 无法在线完成
  • 人形机器人真机数据采集：遥操作与真机部署必须进真实工位，在线无法替代
  • 停产窗口施工：72 小时联调与全厂排产强耦合，纯线下组织
  • 垫资与账期：集成项目的商务条件、验收扯皮与回款博弈在线下完成
  • 实机试机与二手验机：设备真实状态要上手测、上电跑才能确认

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

终端工厂带着「这条线改造值不值、找谁做」的问题来 → 用回收期计算器按统一口径出数 → 查同行业工位案例与集成商交付档案 → 邀约两三家比方案 → 项目终验后回传真实投资额与验收数据 → 案例库越厚，后来者的测算越有底气，集成商也愿意挂档案来接询盘

需要建设的数据表
  • 工位改造案例库（行业/工艺/投资额区间/节拍/回收期/验收口径）
  • 机器人型号参数库（品牌/型号/负载/臂展/重复定位精度/测试条件/样本版本）
  • 集成商档案（行业经验/规模/交付记录/验收纠纷记录）
  • 故障知识库（品牌/型号/报警代码/原因/处置/备件渠道）
  • 政策库（地区/补贴类型/门槛/材料清单/经办口径）
信任来源
  • 参数一律标注出处与测试条件（样本册版本/官网页面），区分「自报」与「核验」
  • 案例只收有合同或验收文件佐证的项目，投资额给区间不给精确数
  • 回收期计算器公开全部假设（人工全成本系数/折旧年限/维保费），用户可逐项修改
  • 集成商档案不做竞价排名，排序依据公示
可做产品形态
自动化改造算账工具站（回收期计算器+同工位案例库+成本基准）机器人选型对比与集成商交付档案站（参数口径统一+真实项目记录）机器人运维知识库（报警代码/故障案例/备件索引，按品牌型号检索）集成项目撮合与标讯监测平台（工厂需求登记+集成商档案+倾向性分析）

验证指标
  • 单次立项测算从「一周 Excel」降到 1 小时内出初稿
  • 案例库与测算结论被写进立项报告/投标文件的次数（目标：月 20+）
  • 工厂发布改造需求后获得集成商有效响应的比例（目标 >50%）
  • 至少 3 家工厂或集成商为档案/测算报告付费

  3. 选集成商时你看什么？被低价中标后烂尾坑过吗？
  4. 一个典型项目从签约到终验要多久？驻场人天比合同多出多少？
  5. 现场返工最常见的原因是什么？来料公差和基面问题占几成？
  6. 验收节拍在合同里怎么定义的？为口径扯过皮吗？
  7. 机器人报警一般多久恢复？处置经验现在存在哪？
  8. 视觉项目 POC 到产线稳定要多久？反光件怎么解决的？
  9. 协作机器人评估过吗？为什么最后用/没用？
  10. 如果一个网站能给你同工位改造案例和回收期基准，你信它的前提是什么？愿意付费吗？
