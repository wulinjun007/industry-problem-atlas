07

纤维及复合材料

先进材料

核心问题国产碳纤维的性能一致性与成本拐点到了吗，设计端为什么不敢用国产料

这个产业赚「把一根丝拉到极致、再变成结构件」的钱：纤维厂在碳化炉边 24 小时守批次，制品厂在模具边磨工艺窗口，事卡在批次一致性的口碑和设计端「没有许用值数据不敢用」的死循环。

细分方向碳纤维玻璃纤维芳纶玄武岩纤维复材制品
典型用户材料研发工程师结构设计工程师工艺工程师下游应用采购检测认证机构
重庆锚点重庆国际复合材料 CPIC（长寿）：全球玻纤头部企业，万吨级超高模玻纤产线，风电高模纱方向开州高性能碳纤维项目：一期 1.2 万吨（重庆产业地图口径），重庆切入碳纤维主赛道江津聚酰亚胺纤维项目补特种纤维品类；承载区县为长寿/开州/江津/永川官方口径短板：高端碳纤维、电子级玻纤对外依赖——与全国「敢不敢用国产料」的关键问题同构

产业核心把丙烯腈、矿石熔体拉成高强度高模量纤维，再织布、浸胶、成型为结构件，替金属减重；赚的是纤维级性能和制品级工程化的双层钱。

产业链地图

上游原料 / 部件 / 设备

PAN 原丝

丙烯腈聚合、纺丝制成原丝，是碳纤维性能与成本的最大变量

吉林碳谷、上海石化等原丝基地原丝的分子量分布与缺陷决定碳纤维强度上限，毛丝断纱的根源常在原丝
树脂与上浆剂

环氧/乙烯基酯/双马树脂体系与纤维表面浆料，决定纤维与基体的界面

道生天合、惠柏新材、上纬新材等树脂厂；上浆剂多为纤维厂自制上浆剂化学结构是各家机密，「环氧型」三个字覆盖了完全不同的东西
织物与毡

多轴向经编、机织布、短切毡、单向布等中间形态

各区域织造厂与玻纤厂自产布线布的铺覆性、毛羽、张力均匀性直接卡自动化铺放与拉挤速度
专用装备与检测

预氧化/碳化炉、池窑漏板、缠绕机、拉挤线、超声 C-scan 等装备与仪器

国产炉窑与复材装备厂、进口设备代理炉温均匀性与张力控制精度决定批次一致性，先进装备仍有进口依赖

中游制造 / 集成 / 流通

碳纤维制造

原丝经预氧化、低温/高温碳化、表面处理、上浆收卷成纱

中复神鹰、光威复材、吉林化纤、中简科技、恒神股份大丝束放量把价格打下来，但高端小丝束与一致性口碑仍落后东丽数十年积累
玻璃纤维制造

池窑熔化拉丝，产无碱粗纱、高模纱、电子布

中国巨石、泰山玻纤、重庆国际 CPIC规模壁垒极深；高模量与低介电电子布是迭代方向，高端电子级玻纤仍对外依赖
特种纤维

对位/间位芳纶、连续玄武岩纤维、聚酰亚胺纤维等品类

泰和新材（芳纶）、江苏等玄武岩纤维企业、重庆江津聚酰亚胺纤维项目材料先于应用规范成熟，设计院「无规范不敢出图」是共同瓶颈
预浸料与中间材料

纤维浸树脂做成预浸料、拉挤板、缠绕纱等可直接成型用材

光威复材、恒神股份、江苏澳盛、上海晋飞等全程冷链、适用期管理、良率损耗是隐形成本大头

下游应用 / 服务 / 终端

风电叶片

玻纤/碳板主梁、蒙皮，是玻纤最大单一市场

中材科技、时代新材、艾郎科技等叶片厂叶片大型化把材料推向高模玻纤与碳纤维拉挤板，疲劳数据是选材胜负手
航空航天

军机民机复材结构件，按积木式验证建立许用值后使用

航空工业复材体系、商飞供应链、光威/中简等军品供应商适航与许用值门槛极高，国产料进型号要数年验证，是「敢用」问题的最深处
低空与体育休闲

无人机/eVTOL 结构件与钓具、球拍、自行车架

低空整机新势力、威海体育器材集群一端要快反开发、一端要适航取证，新公司普遍缺复材工程能力
汽车/氢能/建筑

电池盒与轻量化件、车载储氢气瓶缠绕、碳布加固

车企复材线、中材科技（苏州）、天海工业等气瓶厂、加固施工企业车规审核与成本敏感，气瓶对纤维毛丝与断裂伸长率极挑剔
电子覆铜板

电子级玻纤布做 CCL 增强材料，高频高速板要低介电布

生益科技等覆铜板厂；低介电布长期由日东纺等主导功夫在批次稳定性与布面质量，国产导入卡在终端「谁家用过」的审核

用户角色地图 谁在干活、被考核什么、卡在哪

材料研发工程师
是谁

在碳纤维/特种纤维厂负责原丝-碳化工艺、上浆剂开发与新牌号定型

被考核

新牌号性能达标时间、批次强度 CV、下游投诉次数

用什么干活

单丝拉伸仪、预氧化/碳化线在线记录、实验记录本、文献库

最常见卡点

毛丝断纱成因横跨六道工序，归因靠统计与经验；上浆剂匹配是黑箱

结构设计工程师
是谁

在整机厂（风电/无人机/汽车/低空）做复材铺层设计与强度校核

被考核

减重指标、强度裕度、试验一次通过率

用什么干活

CATIA/Fibersim、Abaqus/Nastran、Excel 材料卡、试验委托单

最常见卡点

国产料没有现成许用值，要么自费几十万建数据，要么保守设计白白增重

工艺工程师
是谁

在预浸料/制品厂（拉挤、缠绕、RTM、模压）负责成型工艺开发与稳定

被考核

良率、单件节拍、工艺窗口宽度

用什么干活

固化曲线记录仪、缠绕机/拉挤线、切片显微镜、CT

最常见卡点

工艺窗口窄且强耦合本厂设备，参数靠试错；预浸料适用期台账人肉管理

质量检测工程师
是谁

在制品厂实验室做入厂复验、过程检验与超声 C-scan 判读

被考核

漏检率、误判废率、批追溯完整度

用什么干活

C-scan/相控阵、万能试验机、切片金相、判废限值文件

最常见卡点

缺陷图谱与判废限值各家自建无公开参照，新人判读全靠老师傅带

下游应用采购
是谁

在整机/制品企业负责纤维、预浸料、电子布的寻源比价与供应商管理

被考核

供应保障、材料成本、质量事故次数

用什么干活

报价单对比表、COA、1688、展会名片、供应商审核检查表

最常见卡点

报价口径对不上（丝束/上浆剂/含碳量各不同），低价料毛丝多综合成本反超

检测认证工程师
是谁

在第三方检测机构或企业实验室排试验矩阵、写材料规范与检测方案

被考核

报告被客户/审核采纳率、周期与单价

用什么干活

GB/T 与 ASTM 标准库、环境箱、万能试验机、报价模板

最常见卡点

同指标不同方法结果对不上，机构水平参差，报告互认难

纤维厂销售/BD
是谁

在纤维/预浸料厂负责把新牌号卖进新应用，陪客户走过验证

被考核

新客户验证进度、吨单价、回款

用什么干活

样品与数据页、检测报告、行业展会、客户试验记录

最常见卡点

客户要求「有同行批量用过才敢试」，玄武岩等新品类没有规范依据连设计院这关都过不去

投资/产业研究员
是谁

在基金/券商/政府平台研判碳纤维产能、价格与格局

被考核

周期判断准确率、标的存活率

用什么干活

年度白皮书、扩产公告、专家访谈纪要

最常见卡点

价格口径混用、产能数据年更宏观，一致性与开工率等关键变量查不到

真实工作场景 每张卡片：什么触发 → 现在怎么做 → 卡在哪 → 值不值得数字化

S01

新机型立项的碳纤维牌号初筛

结构设计工程师
触发事件

无人机/低空整机新机型立项，结构重量按公斤卡，两个月内要定预浸料体系并开模

当前做法

下载东丽 T700/T800 级数据页 → 到中复神鹰、光威等官网找国产对应牌号 → 只找到宣传页和「典型值」→ 找销售要详细数据 → 微信群打听哪家批量用过、毛丝多不多

所需数据

部件载荷工况、重量与预算目标、各家牌号数据页、样品

决策参数

拉伸强度/模量、断裂伸长率、12K/24K 丝束规格、毛丝表现、价格、供货稳定性

具体痛点

进口牌号有几十年公开数据，国产牌号连批次 CV 都不给；「典型值」是挑过的最好批次，拿来做设计等于赌

错误成本

定错牌号，铺放时毛丝拉丝或强度不达标，此时模具已开，返工损失数十万

现有替代

同行微信群打听 + 展会拿样品自己绕纱测

季网站可解证据高
碳纤维牌号T700级12K预浸料选型拉伸模量
🖥 进口-国产牌号对位数据库：按级别/丝束/性能参数级对齐，标注数据出处与测试条件，附真实用户使用反馈入口
S02

从零建立国产碳纤维的设计许用值

结构设计工程师
触发事件

选定国产牌号后，客户或内部强度规范要求给出 B 基准许用值，数据才能写进设计报告

当前做法

按积木式方法排试验矩阵：单向板 0°/90°/±45 拉伸压缩、开孔、挤压、层间，每态 3 批 × 每批 5 件以上，叠加 -55℃/室温/82℃湿态环境 → 总量三四百件 → 委外检测或自建能力，耗时 3～6 个月

所需数据

材料规范、GB/T 3354 与 ASTM D3039/D6641 等试验标准、环境箱与试样加工能力

决策参数

B 基准统计值、批次间方差、湿热退化系数、失效模式有效性

具体痛点

进口料有历史数据可部分借用，国产料每个用户都要从零重测同一套矩阵；各家数据互不共享，全行业在重复烧钱测同一张表

错误成本

一个牌号全矩阵几十万元加半年；不做就只能按保守系数设计，白白多铺 10～20% 层把减重优势吃掉

现有替代

按「典型值×折减系数」保守设计，或托关系找总师单位借数据

季部分可解证据高
设计许用值B基准值积木式验证湿热老化GB/T 3354
🖥 网站做公开许用值数据结构化检索（论文/白皮书/审定文件中的数据带试验条件）+ 试验矩阵模板与价格参考；试样物理试验必须线下做
S03

换国产料引发的等同性验证博弈

工艺工程师
触发事件

采购提议把成熟制品（拉挤板/无人机结构件）的进口碳纤维换成便宜两三成的国产料，设计和质量都摇头，矛盾上会

当前做法

开变更评审会 → 设计提出要做等同性验证（关键性能 3 批对比、覆盖静强度与疲劳、工艺窗口复核）→ 一算验证费吃掉小半年省下的料钱 → 妥协方案是先在非关键件小批量试 → 毛丝/固化异常又退回原牌号

所需数据

现牌号材料规范、两家对比数据、本厂工艺窗口、历史失效记录

决策参数

均值相当性与方差判据、工艺窗口重叠度、疲劳寿命对比、切换批量

具体痛点

换料的真实成本全压在验证和风险上，验证数据做完只服务这一个决定；老板的账本上只有每公斤差多少钱

错误成本

验证不充分批量后分层掉强度，索赔召回；验证太慢错过降价与断供窗口

现有替代

非关键件先试 + 老师傅手感判断，出了问题再说

季部分可解证据高
等同性验证材料替换国产替代变更管理疲劳对比
🖥 网站提供分行业的等同性试验矩阵模板与换料案例库（谁换过、卡在哪、花了多少）；实测与决策仍在线下
S04

进口断供压力下的国产牌号对位

下游应用采购
触发事件

客户要求供应链降依赖，或贸易摩擦导致进口纱交期不稳，管理层要三个月内给出国产备份方案

当前做法

拿现用牌号数据页按强度/模量/伸长率筛国产候选 → 各家寄样 → 自己绕纱测线密度、做单向板比对 → 问销售要批次 CV 遭拒 → 半年出不了结论，只能先囤进口料压库

所需数据

现用牌号数据页、国产候选名单、样品与 COA

决策参数

强度/模量/伸长率对位、批次 CV、上浆剂类型、丝束规格、价格与交期

具体痛点

「同级 T700」没有权威定义，各家实际分布差得远；断供压力下最容易病急乱投医，切错再切回要双倍验证

错误成本

切换失败再回头，双倍认证成本；或断供时无备份直接停产

现有替代

囤一年用量的进口料（占资金，预浸料还有冷藏有效期）

月网站可解证据高
牌号替代国产碳纤维T700S供应链备份断供
🖥 国产-进口对位速查表（参数级对齐+数据出处）+ 各牌号公开应用案例清单，输入现用牌号直接出候选名单与缺口提示
S05

报价口径对不上的碳纤维招标比价

下游应用采购
触发事件

季度招标，五家 48K 大丝束报价吨价差三四成，领导要求说明贵的一家贵在哪

当前做法

拿报价单逐家对 → 发现上浆剂体系、线密度、含碳量、筒纱重量各不相同 → 说不清贵是不是真好 → 按低价中标 → 拉挤时毛丝多废品率升，综合成本反超又回到老供应商

所需数据

各家报价单、COA、样品、本厂拉挤废品率记录

决策参数

线密度、拉伸强度与 CV、上浆剂兼容性、退绕性、账期

具体痛点

没有「单位强度价格」或「废品率修正后成本」的统一口径；毛丝量没有仲裁方法，吃了亏也说不清

错误成本

低价纱废品率高，综合成本反超两成；换回原供应商被坐地涨价

现有替代

Excel 手算换算 + 每家小试一卷（一周起步）

周网站可解证据中
大丝束48K碳纤维价格比价毛丝
🖥 比价工具：录入报价自动换算单位强度成本，附上浆剂兼容性提示与退绕性用户口碑标签
S06

换树脂体系后界面强度掉了

材料研发工程师
触发事件

客户把树脂从标准环氧换成耐温更高的双马，或拉挤厂改用乙烯基酯，制件层间剪切强度明显下降

当前做法

找纤维厂问上浆剂型号 → 答复「商业机密，只能说是环氧型」→ 排列组合试不同树脂促进剂与固化制度 → 每轮做单向板与短梁剪切，两周一批

所需数据

上浆剂模糊类型、树脂体系与固化制度、层间剪切数据

决策参数

层间剪切强度、失效模式（界面/基体/纤维）、工艺窗口重叠

具体痛点

上浆剂是界面性能的黑箱，「环氧型上浆剂」从乙烯基酯到双马都能叫，匹配全靠排列组合地试

错误成本

界面不良批量分层，一炉制品报废数万元；开发周期拖两三个月

现有替代

改买纤维厂同体系预浸料成品（贵且被绑定）

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 牌号对位与选型：进口-国产碳纤维/芳纶按级别、丝束、性能参数级对齐，标注数据出处与测试条件
  • 设计数据导航：公开许用值与试验数据结构化检索、试验矩阵模板与委外报价参考
  • 采购口径统一：单位强度成本换算、分级价格指数、产能投产日历与锁价参考
  • 工艺参数速查：预浸料适用期条款、固化制度、缺陷图谱与判据参考
  • 标准与检测导航：材料×指标×国标/ASTM×机构映射，含方法差异点提示
  • 余料与回收料供需登记：带批次数据的挂牌，减少临期料浪费

🚧 必须线下 / 网站只能辅助

  • 积木式验证与等同性测试：数百件物理试样加多环境条件，无法在线替代；网站只能给矩阵模板与案例
  • 产线工艺调试：碳化毛丝、缠绕断纱、RTM 试模强依赖本线设备实测，网站给故障树参考
  • 无损检测与缺陷判定：实件实测实判，网站提供图谱与判据参照
  • 供应商现场审核与信任建立：冷链、追溯、留样要进厂核验
  • 适航认证与出口管制的正式意见：责任主体在审定机构与律所
  • 疲劳数据等商务敏感数据：仍在少数厂商手中，靠商务渠道获取

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

设计与采购带着「国产牌号能不能替进口」来 → 查对位库与公开性能数据（每条标注测试方法与条件）→ 用试验矩阵工具生成验证方案与预算 → 回传自家入厂复验与试用数据 → 数据越多对位越可信，后来者依赖存量档案

需要建设的数据表
  • 牌号库（级别/丝束/线密度/强度模量与 CV/上浆剂类型/测试标准）
  • 公开试验数据库（牌号/性能/环境条件/试样数/数据来源）
  • 价格与产能库（级别/报价/日期/投产公告）
  • 标准与机构库（标准号/方法差异/机构资质/周期费用）
  • 余料供需表（批次/复验结果/品类/数量/残值）
信任来源
  • 每条性能数据标注测试标准、试样数量与环境条件
  • 区分「自报」与「核验」两种数据来源并可见
  • 引用白皮书、标准原文等公开出处并注明日期
  • 先例案例只收公开可查事实，不编造
可做产品形态
