脑机接口及脑科学

未来产业

核心问题非侵入 BCI 哪类临床/康复场景最先形成真实支付，监管与伦理路径怎么走

这个产业赚的是「把脑电变成可用的康复、调控和交互工具」的钱，当前收入大头来自高校科研设备采购、医院神经调控与康复治疗、消费级头环；神经工程研发、临床医生和注册专员在干活，事卡在疗效证据不足、注册与伦理路径不清、患者家庭找不到可信信息。

细分方向侵入/非侵入BCI神经调控脑健康监测康复训练科研设备
典型用户临床与康复科医生神经工程研发科研院所器械注册专员患者家庭
重庆锚点重庆脑与智能科学中心联合新桥医院，公开报道口径下 2025 年 12 月在 Science 子刊发表意识解码成果重医附属康复医院 2026 年 3 月完成首例卒中康复 BCI 应用（公开报道口径），卒中康复是本地最先落地的临床场景侵入式 BCI 列入重庆智慧医疗「双十」攻坚；云脑医疗等本地团队切入脑电与神经调控方向（公开资料口径）脑机接口及脑科学为重庆 18 个新星产业中定位最早期的一个：临床转化起步、暂无公开产值数据，短板集中在植入长期安全性、适应症窄、伦理审批门槛

产业核心围绕大脑与神经系统的信号读写：采集并解码脑电、施加神经调控，做出科研设备、康复训练与脑健康监测产品，现阶段赚「科研采购+临床康复+消费级」三个钱袋的钱。

产业链地图

上游原料 / 部件 / 设备

脑电采集芯片与电极

提供 EEG 模拟前端芯片、干/湿/半干电极、柔性植入电极材料

进口芯片原厂与国产模拟芯片团队、柔性材料实验室高通道低噪声模拟前端长期依赖进口方案，国产替代刚起步、评估板交期长
脑科学基础研究与算法

神经解码、神经调控范式、脑机理研究，以论文与专利形式沉淀

高校脑科院系、科研院所、医院研究团队成果工程化转化率低，公开数据集与自采数据分布差异大
植入体材料与封装

植入电极的生物相容性材料、柔性封装、导电凝胶等耗材

特种材料厂、医疗器械上游供应商植入体长期在体安全性数据积累不足，是侵入式路线公认的短板
算力与神经数据基础设施

神经数据存储、模型训练算力、数据脱敏与合规流转

云厂商、超算中心、医院信息科神经数据是否属敏感个人信息尚无细则，数据出库与共享边界模糊

中游制造 / 集成 / 流通

非侵入 BCI 设备

EEG 头环/放大器与解码软件，覆盖消费级与医疗级

消费级头环厂商、医疗级 BCI 创业公司消费级「专注/睡眠/放松」先行但口碑两极，医疗级多卡在注册与临床证据
神经调控设备

rTMS/tDCS/tVNS 等刺激设备用于精神、神经与康复科室

成熟医疗器械厂商当前最接近真实支付的商用方向，但适应症边界与循证等级仍有争议
侵入式 BCI

皮层/深部植入电极系统、手术辅助与在体解码

临床研究主导的团队，与神经外科共建全球均处临床试验阶段，长期安全性、适应症窄、伦理审批门槛是三大坎
科研设备与工具链

研究级放大器、导联帽、范式设计软件、数据集

科研仪器商、开源社区高校实验室是当下最稳定的付费客户，采购跟着基金周期走

用户角色地图 谁在干活、被考核什么、卡在哪

神经工程研发工程师
是谁

在 BCI/神经调控公司负责采集硬件与解码算法，从实验室原型做到可交付产品

被考核

信号质量、解码准确率、跨被试/跨用户的稳定性

EEG 放大器、MATLAB/Python、开源数据集、示波器与评估板

最常见卡点

S01

为卒中患者制定 BCI 辅助康复方案

康复科/神经科医生
触发事件

卒中后 1~3 个月患者上肢功能停滞，家属在诊间问「听说脑机接口能康复，我们能不能做」

当前做法

翻近年指南与共识 → 核对厂商提供的临床资料 → 问同行科室的使用体验 → 结合科室现有 rTMS/tDCS 设备开方案

所需数据

患者病程、损伤部位、认知与运动功能评估（FMA、MMSE 等）、厂商适应症材料

决策参数

适应症与禁忌症、证据等级、疗程与频次、医保/自费支付方式、科室设备可得性

具体痛点

厂商材料与指南口径对不上，同一场景不同文献结论互相矛盾；家属以为「戴上就能好」，期望管理比治疗本身还费劲

错误成本

方案选错，患者错过黄金恢复期，医患纠纷风险

现有替代

科室微信群问同行 + 等厂商上门宣讲

周网站可解证据中
脑机接口康复卒中康复运动想象rTMS适应症
🖥 「适应症×设备×证据等级×支付方式」对照库，每条证据标注指南/共识/文献出处，医生可当场调出来给家属看
S02

EEG 采集数据的伪迹处理调试

神经工程研发工程师
触发事件

新一批被试数据里眨眼、咬牙、头动的伪迹淹没有效节律，离线指标难看

当前做法

重跑滤波链 → 调 ICA 分量剔除 → 逐段人工标记坏导联 → 换参数重算指标，一晚上过去

所需数据

原始 EEG 数据、导联布局、采样率、行为事件标记

决策参数

带通滤波范围、ICA 分量判别、坏段剔除阈值、有效 trial 数下限

具体痛点

没有通用的伪迹处理参数，每台放大器、每个被试都要重调；论文里的方法搬到自己数据上就复现不出来

错误成本

把有效信号当伪迹删掉，结论作废、被试重招重采

现有替代

用 EEGLAB/MNE 默认参数跑一遍 + 师门内部经验口传

日必须线下证据高
EEG伪迹ICA去伪迹滤波参数脑电预处理
⛔ 线下原因：伪迹处理强依赖具体数据集与放大器特性，只能逐批实调——网站只能做预处理方法教程与故障对照表
S03

课题组采购 EEG 放大器选型

科研课题组负责人
触发事件

新基金到账要配 32/64 导放大器，几十万预算，采购催论证材料

当前做法

查厂商官网参数表 → 找用过的人打听稳定性与售后 → 等展会摸样机 → 写采购论证报告

所需数据

课题需求（通道数/便携性/与眼动刺激设备同步）、各家参数表、报价、同行口碑

决策参数

输入噪声、共模抑制比、采样率、阻抗检测、同步接口、耗材与售后响应

具体痛点

各家标称参数的测试条件不同，噪声指标没法直接比；导电膏、电极帽寿命与售后响应全靠私下打听

错误成本

买错设备，几十万预算锁死 5~8 年，课题受制

现有替代

同行微信群问 + 展会看样机

季网站可解证据中
EEG放大器脑电设备选型64导科研采购
🖥 科研 EEG 设备参数库：标注每个参数的标称测试条件，叠加真实用户的稳定性与售后评分
S04

BCI 产品的医疗器械分类界定

器械注册专员
触发事件

新产品要上市，老板和法务对「按消费电子卖还是按二类医疗器械注册」拿不定

当前做法

研读《医疗器械分类目录》与预期用途描述 → 检索同类产品注册证 → 拿不准就向药监部门提分类界定申请 → 等复函期间产品规划停摆

所需数据

产品预期用途描述、宣称功能清单、同类已注册产品证号、分类目录

决策参数

是否宣称诊断/治疗功能、作用部位、风险等级、临床评价路径（豁免/同品种/临床试验）

具体痛点

「放松训练」和「辅助治疗」一句话之差，注册周期差两年；各地对同类产品口径不一，边界案例先例难检索

错误成本

路径判断错，按消费电子上市后被认定违规宣称，下架整改甚至处罚

现有替代

请注册咨询代理（报价十几万）+ 打电话问审评部门

季部分可解证据中
医疗器械分类界定二类注册预期用途临床评价NMPA
🖥 网站建分类界定先例库：按宣称功能聚类已批产品证号与监管口径；正式界定复函仍要走药监程序
S05

医院康复中心写 BCI 设备招标参数

医院设备采购
触发事件

康复中心建设立项，几十万预算买 BCI 康复训练系统，限期出招标技术参数

当前做法

找兄弟医院招标文件改 → 参考厂商提供的参数建议 → 过院内论证会 → 公告发出后被质疑参数指向性

所需数据

科室需求清单、各家产品彩页、同类医院招标文件

决策参数

导联数与信号指标、训练范式数量、注册证类别、培训售后条款、验收指标可测性

具体痛点

参数写宽了招来杂牌、写严了被投标方投诉「指向性」；验收时信号质量类指标科室没有能力复测

错误成本

流标或买回不能用，预算执行被审计盯上

现有替代

依赖集成商与厂商代写参数（天然偏向）

季部分可解证据中
招标参数BCI康复设备医疗设备采购验收标准
🖥 网站提供可复用的招标参数模板库与流标/投诉案例集；具体参数取舍仍要院内论证
S06

患者家庭甄别侵入式 BCI 临床试验真伪

患者家庭照护者
触发事件

家人因脊髓损伤瘫痪，刷到侵入式脑机接口人体试验招募的新闻，想报名又怕被骗

当前做法

搜新闻与公众号 → 加病友群打听 → 对照招募条件自查 → 打报名电话，被要求「先交检查费」时分不清真假

所需数据

患者病情与检查资料、各家试验招募公告、病友群经验

决策参数

研究阶段、牵头医院资质、是否收取费用、入组排除条件、风险告知完整性

具体痛点

分不清「科研入组」与「收费治疗」，官方注册库查询门槛高，病友群里骗局与真机会混杂；选错轻则白花钱，重则延误规范治疗

错误成本

被骗数万元，或错过正规康复窗口

现有替代

病友群口口相传 + 找信任的医生私下问

偶发网站可解证据中
脑机接口临床试验植入式BCI招募瘫痪治疗渐冻症防骗
🖥 面向家属的 BCI 临床研究对照页：按病种整理官方注册编号、阶段、牵头医院、是否收费，并固定放置防骗检查清单
S07

解码算法跨被试泛化失败

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 循证导航：适应症×设备×证据等级×支付方式的结构化对照，帮医生与患者家庭判断哪类场景真的有效、真的有人付费
  • 临床试验对照页：把分散的 BCI 临床研究按病种整理注册编号、阶段、牵头医院、是否收费，附防骗检查清单
  • 科研与医院采购选型器：EEG 放大器、神经调控设备的参数归一对比 + 真实用户稳定性与售后口碑
  • 注册与伦理知识库：分类界定先例、创新通道论证框架、知情同意要素清单
  • 被试与患者招募双向登记：科研课题需求与愿意参与的人群结构化匹配
  • 自费 BCI 康复项目档案：按城市沉淀机构注册证、疗程价格区间与公开证据对照

🚧 必须线下 / 网站只能辅助

  • 信号调试与算法适配：每个被试/患者的数据特性不同，必须实测调参，网站只能给方法教程与故障对照
  • 植入手术与临床治疗：侵入式 BCI 的手术、术后随访和康复训练本身就是线下医疗行为
  • 疗效判断：功能量表评估与医生查体无法在线替代，消费级设备的「脑波报告」不能当临床结论
  • 伦理上会与注册答辩：责任主体在线下机构，网站只能帮着把材料准备到能过会的程度
  • 设备进院的商务流程：科室拜访、院内论证、招标验收都依赖线下关系与现场
  • 设备维修与计量：放大器基线漂移、电极阻抗异常要现场排查处理

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

患者家庭带着「BCI 治疗靠不靠谱、哪里能做」来 → 查适应症与临床试验对照页 → 留下病种与所在城市 → 平台把可入组研究与本地可及项目推回给用户和医院 → 每次问询沉淀成「哪类场景真实有需求」的数据，直接验证 keyQuestion 里「哪类场景最先形成真实支付」

需要建设的数据表
  • 适应症×设备×证据等级库（指南/共识/文献出处）
  • 临床试验登记索引（官方注册编号/阶段/入组条件/是否收费）
  • 设备参数库（导联数/采样率/噪声/注册证号）
  • 医院与科室档案（神经调控基础/伦理通道/已装设备）
  • 自费项目档案（城市/疗程价/公开证据/口碑）
信任来源
  • 每条证据标注指南/文献/试验注册编号与日期
  • 临床试验只引用官方注册库编号，不自行解读疗效承诺
  • 医院与设备档案区分「公开可核验」与「机构自报」，颜色区分
  • 患者侧页面固定放置风险与防骗提示

访谈对象
康复科/神经内科使用过 BCI 或神经调控设备的医生 3~5 人BCI 公司注册专员与产品负责人各 2 人医院机构办/伦理办专员 2~3 人卒中与渐冻症患者家庭照护者 3~5 人高校 EEG 课题组负责人 2~3 人
验证指标
  • 患者家庭侧：「能不能做/去哪做」的单次咨询自我解决率（目标 60% 以上）
  • 医生与科研侧：选型对比耗时从数周降到 2 天内
  • 入组转化：对照页带来的临床试验有效问询数（目标月 30+）
  • 付费验证：至少 3 类付费方（设备厂商/医院/科研课题组）愿意为档案或线索付费
访谈问题清单（12）
  1. 你上次向患者或家属解释 BCI 治疗时，他们最常问什么？你从哪里找答案？
  2. 选 BCI/神经调控设备进科室时，哪个证据最打动你？哪个你最不信？
  3. 有没有患者拿着自购头环的「脑波报告」来问诊？你怎么处理的？
  4. 注册分类界定时，你们产品在哪一步最不确定？有没有遇到各地口径不一的情况？
  5. 伦理会上被问得最多的三个问题是什么？哪个最难过？
  6. 招募被试/患者入组时，最有效的渠道是什么？卡在哪类人身上？
  7. 侵入式临床试验的患者咨询里，家属最担心什么、最容易被什么误导？
  8. 自费 BCI 康复疗程，患者家庭能接受的价位是多少？他们用什么判断「值不值」？
  9. 科研设备选型时你实际比较哪些参数？哪些标称值你从来不看？
  10. 医院招标 BCI 设备时验收怎么测？有没有测不出来的指标？
  11. 如果有一个 BCI 循证导航网站，你愿意推荐给患者吗？顾虑是什么？
  12. 你们和医院共享神经数据时，合规审查卡在哪一条？
