06

农机装备

智能装备

核心问题丘陵山区到底需要什么农机，购机补贴与作业服务的账怎么算

这个产业赚「机器替人下地」的钱：厂商卖机、机手卖作业、经销商卖服务与配件；事卡在丘陵山地的巴掌田装不下为平原设计的机，以及补贴、作业量、回本周期这三笔账没人给算清。

细分方向丘陵山地农机收割机植保无人机畜牧设备农机自动驾驶
典型用户农机手与合作社农机经销商农机化管理部门装备厂商产品经理作业服务组织
重庆锚点重庆以丘陵山地为主，耕地细碎（「巴掌田」「鸡窝地」），宜机化改造是农机下地的前置工程，是丘陵农机适应性问题的典型样本重庆产业地图口径点名鑫源农机与西南大学，是本地山地农机整机与研发的代表力量梁平农用无人机保有量居全市前列、极飞落点梁平，目标2028年农用无人机年作业500万亩次綦江横山无人农业试验区、江津江小白未来农场等丘陵无人化示范场景先行先试

产业核心造出适合不同地形、作物、农艺的农业机械（耕整/种植/田间管理/收获/植保/养殖设备），靠整机销售、作业服务和售后配件网络赚钱。

产业链地图

上游原料 / 部件 / 设备

柴油机与核心零部件

提供小缸径柴油机、液压件、传动/离合、履带、轮胎、刀片等基础部件

常柴、全柴、潍柴等发动机厂，液压与传动件供应商丘陵小机型依赖小缸径柴油机与小型液压件，易损件寿命直接决定口碑
电控与智能化部件

农机专用ECU、北斗定位终端、自动驾驶控制器、计亩与监测传感器

华测导航、丰疆智能、博创联动等智能农机供应商农机专用电控长期偏弱，国产替代进行中，自动驾驶已成主粮区标配
钢材与基础材料

型钢、弹簧钢、刀片用钢等原材料

区域钢贸与材料厂割刀、犁尖等易损件用材差异是杂牌机与品牌机的隐形分水岭
农机试验鉴定机构

省级农机鉴定站承担推广鉴定，出报告供进补贴目录

各省农机鉴定站及其承担机构推广鉴定证书是进补贴额一览表的门票，鉴定排期常卡住新机型上市

中游制造 / 集成 / 流通

动力机械

大中小型拖拉机、履带拖拉机、微耕机

中国一拖、潍柴雷沃、约翰迪尔、久保田，以及川渝湘黔微耕机产业带大中拖同质化打价格战，丘陵山区缺专用底盘与爬坡能力达标机型
收获机械

谷物联合收割机、山地小型收割机、玉米/油菜等专用收获机

潍柴雷沃、久保田、星光农机、中联农机平原大机型下不了细碎地块，丘陵专用收获机品种少、可靠性弱
植保机械与农用无人机

植保无人机、喷杆喷雾机及飞防作业服务

大疆农业、极飞科技卖机器同时卖作业服务，飞行数据与作业记录掌握在厂商平台手里
畜牧与养殖设备

自动料线、环控系统、粪污处理、挤奶与集蛋设备

大牧人、丰尚等养殖工程与设备厂商非标定制为主，参数与运行实测数据不公开，选型靠同行口碑
丘陵山地专用农机

山地履带拖拉机、果园轨道运输机、小型收获与搬运机械

鑫源农机等重庆及西南本地企业，西南大学等研发力量小厂多、品牌弱、销量小，可靠性口碑靠口口相传，缺公开的适应性参数

下游应用 / 服务 / 终端

农机经销与服务网络

区县经销商负责整机销售、补贴代办、配件供应与三包服务

各县农机经销商及其乡镇网点替用户垫补贴资金、旺季三包成本高，是产业链资金与信息的关键节点
农机手与农机合作社

购机自营或对外承接作业，跨区流动作业

村社农机大户、农机专业合作社购机决策=补贴+预期作业量+回本周期，账算不清就买错
作业服务与托管组织

代耕代种代收、统防统治、飞防队的组织与调度

农业生产托管服务组织、飞防队按亩计价承接整村订单，报价缺行情参照，调度靠电话
规模种植与养殖场

农场、果园、规模养殖场的成套设备选型与运维

种植企业、规模猪场牛场禽场设备选型偏非标成套，极端天气下设备故障直接变生物资产损失
农机化管理部门

购机补贴资金管理与机具核验、牌证监理、鉴定推广

农业农村部农机化司及省市县农机化管理部门补贴目录与结算节奏决定全行业市场节拍，逐台核验人少机多

用户角色地图 谁在干活、被考核什么、卡在哪

农机手（含飞手）
是谁

在合作社、服务组织打工或自家购机，开收割机/拖拉机或操控植保无人机

被考核

作业亩数与净收入、故障停工天数、事故零记录

用什么干活

手机计亩APP、微信接活群、跨区作业证、随车工具箱

最常见卡点

找活靠熟人转介绍，机器农忙趴窝一天误一季，计亩面积常被抹零

合作社理事长
是谁

管农机合作社，决定买什么机、接什么活、怎么给社员分账

被考核

机具利用率、每亩作业净利、补贴资金到账

用什么干活

补贴APP、作业合同与记账本、社员微信群

最常见卡点

购机账算不清：补贴额、一年能干多少亩、几年回本全靠估计和听说

农机经销商
是谁

在区县代理一个或几个整机品牌，卖机、代办补贴、供配件、做三包

被考核

销量与返利、库存周转、垫资规模、三包成本

用什么干活

厂家进销存、补贴办理系统、客户微信群

最常见卡点

补贴资金结算慢要垫货款，旺季三包吃人吃钱，淡季库存压仓

作业服务组织负责人
是谁

经营农业生产托管、代收代种或飞防队，对接农户与机手

被考核

托管面积、亩均毛利、订单履约率与投诉率

用什么干活

托管合同模板、调度台账、计亩工具

最常见卡点

托管报价没有公开行情，农忙调度十几台机靠电话和记忆

装备厂商产品经理
是谁

在农机主机厂负责机型定义、适应性改进与竞品对标

被考核

新品销量、市场故障率、售后成本占比

用什么干活

销售与三包报表、竞品样机、农机展与田间演示会

最常见卡点

丘陵山地真实田块条件与故障数据拿不到，机型定义靠平原经验外推

农机化管理部门科员
是谁

在农业农村局农机化科管补贴资金、机具核验与牌证监理

被考核

补贴结算率、核验差错率、监理事故率

用什么干活

补贴管理系统、核验记录表、Excel

最常见卡点

人少机多地又散，逐台核验跑不完；资金拨付不在手里，考核却压在头上

畜牧场设备主管
是谁

在规模养殖场负责料线、环控、粪污设备的选型、安装与运维

被考核

设备完好率、极端天气零事故、设备折旧摊入成本

用什么干活

环控器与设备台账、备件清单、厂家售后电话

最常见卡点

非标设备无公开参数可查，换一家厂商等于重新试错一遍

农机鉴定/推广工程师
是谁

在省级农机鉴定站做推广鉴定试验与机型选型推广

被考核

鉴定周期、报告质量与公正性

用什么干活

试验大纲、田间测试仪器、测试田块

最常见卡点

鉴定排队加上作物季节窗口，报告出慢一季企业就晚一年进目录

真实工作场景 每张卡片：什么触发 → 现在怎么做 → 卡在哪 → 值不值得数字化

S01

麦收季跟着麦浪走：跨区路线怎么定

农机手（含飞手）
触发事件

五月小麦自南向北成熟，机手要决定今年跨区先去湖北还是直上河南，以及下个月去哪

当前做法

在跨区作业微信群和短视频里打听 → 回县里办《联合收割机跨区作业证》→ 凭去年经验加熟人电话定路线 → 到了地方再找本地中介接活

所需数据

各地小麦成熟期、当地作业价格、机具保有量、跨区作业证、高速免费通行政策

决策参数

作业单价、当地机具饱和度、转移里程与成本、天气窗口

具体痛点

成熟期和价格行情散在微信群与短视频里，没有可核对的公开行情；去早了没麦可割，去晚了地已收完，来回白烧油钱过路费

错误成本

路线错一趟，一季跨区作业收入少三分之一

现有替代

熟人带路 + 本地中介介绍（被抽成一成上下）

年网站可解证据高
跨区作业证麦收时间收割机作业价格跨区路线
🖥 跨区作业信息站：分县成熟期日历+历年分县作业价格行情+机具缺口测算+办证与高速免费通行指引
S02

割一亩算一亩：计亩面积起争议

农机手（含飞手）
触发事件

一块不规则坡田收完，农户咬定面积没那么大，拒付差额几十块

当前做法

各说各的理 → 翻出手机计亩APP的轨迹截图 → 农户只认土地承包证面积 → 僵持之下抹零成交 → 下一块地照旧

所需数据

GPS轨迹与测亩截图、土地承包证面积、田块实际边界、坡地情况

决策参数

计亩口径（承包面积/实测面积/坡地折算）、单价、田头掉头与边角损耗

具体痛点

丘陵地块不规则、坡地计亩没有公认折算口径，同一块地三台机器测出三个数；争议发生在田头，没人说得清也没处评理

错误成本

每季被抹掉的零头累计数千元，还伤客情

现有替代

手机计亩APP截图 + 微信群晒轨迹自证

周部分可解证据中
计亩器作业面积测量收割机收费面积纠纷
🖥 网站可给统一计亩口径说明、坡地折算规则模板与争议处理流程卡；田头现场丈量与协商必须线下
S03

农忙当天趴窝：三包等不起

农机手（含飞手）
触发事件

收割季第三天割台链条断、皮带烧，机器停在田里，后面排队的两户农户在催

当前做法

打厂家400电话 → 转到县经销商 → 服务员说配件要从市里调 → 等一天甚至更久 → 自己找乡镇修理铺用杂牌件先凑合干活

所需数据

故障现象、整机型号与出厂编号、易损件规格、就近服务点与配件库存分布

决策参数

三包响应时效、配件到位时间、误工损失、自费修理与杂牌件代价

具体痛点

农忙一天能割上百亩，趴窝一天损失上千元还砸口碑；三包网络到县以下就是「电话很近、人很远」，配件永远差一根皮带

错误成本

误农时赔款加客户流失，一季损失可能上万元

现有替代

自己囤一箱易损件 + 乡镇修理铺 + 微信群里问同行

周必须线下证据高
收割机故障三包服务农机配件误农时
⛔ 线下原因：换件与抢修必须有人带着配件到田头——网站只能做故障现象/易损件图库对照、就近服务点与配件库存查询的辅助
S04

这台机买回来几年回本

合作社理事长
触发事件

补贴名额批下来了，在履带拖拉机和小型收割机之间二选一，理事长要向全体社员交代这笔账

当前做法

听经销商说「两年回本」→ 自己拿小本子凭感觉估作业量 → 打电话问邻村合作社实际数 → 各说各样，最后拍脑袋定

所需数据

机型价格与补贴额、本地作业季节长度、预期作业亩数、油价、机手工钱、维修与折旧

决策参数

年作业亩数、亩均作业价、油料与人工成本、折旧年限、故障率

具体痛点

查不到分地块条件的作业量基准：同一台机在平原一年上千亩、在丘陵可能只有三四百亩，公开资料全是平原口径，丘陵的账算不了

错误成本

买错机型机具闲置吃灰，十几万投入变成负资产

现有替代

问同行 + 经销商口头承诺 + 自己拿纸笔估

年网站可解证据中
农机回本购机补贴履带拖拉机作业成本
🖥 购机回本计算器：按地块条件（坡度/地块面积/作物）给年作业量基准区间，输入油价工钱补贴额，输出回本测算报告
S05

补贴目录对表：在不在范围、补多少、几时到账

合作社理事长
触发事件

想买的机型到底在不在补贴范围、补多少钱、资金多久到账，社员等着这笔钱周转

当前做法

到省农业农村厅网站翻补贴额一览表PDF → 打电话问经销商 → 在补贴APP上提交申请 → 之后只能等，进度靠反复打电话问

所需数据

当年补贴机具种类范围、补贴额一览表、购机发票、身份与账户信息

决策参数

补贴额分档、单机封顶、资金结算周期、报废更新叠加政策

具体痛点

目录是一份几十页的PDF表格，官方名称和商品名对不上号，自己那台机到底对应哪一档要靠问；资金到账时间没有公开口径，慢的年份要跨年

错误成本

选了不在目录或档位低的机型，平白多花几万元

现有替代

经销商代办 + 打电话问县农机化科

年网站可解证据高
农机购置补贴补贴额一览表补贴APP结算进度
🖥 补贴政策导航站：按商品名/型号检索补贴额与分档、生成申报材料清单、晒各县实际到账周期口碑
S06

巴掌田选机型：坡地改完配什么机

合作社理事长
触发事件

村里宜机化改造完工，坡地归并成几亩一块的梯田，要配一套从耕整到收获的机器

当前做法

请几家经销商来看地 → 各推自家代理的机型 → 现场试机一回 → 凭感觉下单 → 用一季后发现爬坡没劲、地头转不过弯、机身宽了压苗

所需数据

地块坡度、地块长宽与耕作面、土壤类型、作物与行距株距、机耕道与转场条件

决策参数

最小作业幅宽与整机宽度、爬坡能力、地头转弯半径、底盘离地间隙、可靠性口碑、价格与补贴档

具体痛点

没有一张「地块条件×机型」的适配对照表：厂商参数页只写功率和幅宽，不写「坡度多少度以下能干活、地头多短能掉头」，买错一台全村跟着别扭

错误成本

一套机器十几万不适应本地地块，拖垮全村宜机化改造的信心

现有替代

邻村看样机 + 展会看样 + 厂家下乡演示会

季部分可解证据中
丘陵山地农机宜机化改造山地拖拉机机型选型
🖥 网站可做「地块条件→候选机型」选型器与真实用户口碑档案（标明适用坡度与地块下限）；最终拍板仍需下田试机
S07

经销商替客报补贴：垫资与核验来回跑

农机经销商
触发事件

错误成本

代理错品牌，一年销量与三包成本双输

厂家区域经理推荐 + 同行私下打听

农机鉴定/推广工程师
触发事件

当前做法

鉴定机构少、季节窗口刚性，企业催得越急测试条件越容易被将就，数据一失真就误导补贴分档；报告慢一季，企业晚一年

错误成本

报告延误一年丢一季销量；数据失真扭曲全行业分档基准

现有替代

加急协调 + 异地委托其他省份鉴定机构

农机购置与应用补贴制度

自《农业机械化促进法》实施以来全国性购机补贴持续二十余年，2024年起又叠加大规模农机报废更新政策

→ 对本图含义：补贴目录与补贴额是全行业买卖决策的锚，把政策口径讲清楚、把账算明白的信息服务是刚需入口
小麦跨区机收

每年麦收季节联合收割机沿长江中下游向北辗转河南、山东等地抢收，持续二十余年，是公开报道最多的农机流动性作业

→ 对本图含义：成熟期与作业价格这类时空信息直接就是机手的收入，天然适合做成网站化行情
极飞科技与大疆农业

把植保无人机从卖硬件推进到飞防作业与统防统治服务，公开报道其累计作业面积以亿亩次计

→ 对本图含义：农机竞争正从卖机器转向卖作业服务，飞手与服务组织成为新的决策入口，作业数据平台就是护城河
丘陵山区宜机化改造

重庆等西南省市多年推进坡耕地整理、机耕道建设与细碎地块归并，作为农机下地的前置条件写入公开政策文件

→ 对本图含义：丘陵农机是「机—地—作物」系统问题，地块条件数据是一切选型的第一输入
北大荒建三江无人化农场试点

建三江等地公开报道的无人化农场试点，北斗自动驾驶与无人作业在平原大农场规模化验证

→ 对本图含义：平原大农机的智能路线搬不到丘陵山区，适应性是两条不同的技术路线，也是本条目的差异化空间

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 算账工具：购机回本计算器、托管报价计算器、报废与二手残值对照，把补贴/作业量/回本三笔账一次算清
  • 补贴与目录导航：补贴额一览表按商品名检索、申报材料清单、被打回原因档案、各县到账周期口碑
  • 作业信息聚合：分县成熟期日历、跨区与托管作业价格行情、飞防限飞区与报备指引
  • 机型选型与口碑档案：地块条件到候选机型的选型器，厂商/机型/服务商的真实故障与履约档案
  • 售后知识库：故障现象与易损件图库对照、配件通用型号、应急处理手册
  • 厂商与展会情报沉淀：代理政策、样机参数、竞品口径的结构化档案，逐年累积可检索

🚧 必须线下 / 网站只能辅助

  • 田间抢修与三包换件：必须有人带配件到田头，网站只能做故障对照与就近服务点查询的辅助
  • 机具核验与鉴定测试：核验要见实机见人，鉴定要见实机实田实作物，均为线下刚性环节
  • 买机前的试乘试驾与信任建立：样机演示、下田试机、签代理与托管合同都在线下
  • 农忙调度与撮合的执行环节：机手习惯电话与熟人，临时变更多，线上看板落不了地
  • 事故定责、保险理赔与调解：责任划分和资金兑付依赖线下程序
  • 极端天气下的养殖设备抢修：生物资产保卫战，纯线下的人和备件

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

机手或合作社带着「这台机在我这种地行不行、补贴怎么拿、一亩怎么报价」的问题来 → 用选型器与算账工具出结论 → 查档案库核对机型与厂商口碑 → 把自己的作业量、价格、故障记录回传成行情数据 → 数据越滚越厚，后来者离不开存量档案

需要建设的数据表
  • 机型参数库（机型/幅宽/动力/适应坡度/地块尺寸下限/补贴额分档）
  • 补贴政策库（目录/补贴额/申报口径/各县到账周期/地区）
  • 作业行情库（作物/环节/地形/成交价/时间/样本量）
  • 故障与口碑档案（机型/故障模式/维修成本/服务商响应时效）
  • 地块条件档案（区域/坡度分布/地块面积分布/宜机化改造进度）
信任来源
  • 补贴额以官方一览表原文为准，注明文号与发文年份
  • 行情价标注样本量、时间与地区，不冒充官方指导价
  • 机型参数区分「厂商标称」与「用户实测」，颜色与标签区分
  • 公开案例只收有出处的事实，标注来源与日期
可做产品形态
补贴与算账工具站（补贴额检索+回本/报价/残值计算器）丘陵山地机型选型器（地块条件输入，输出候选机型与真实口碑）跨区作业信息站（成熟期日历+作业价格行情+办证与通行指引）机型/厂商/服务商档案库（故障口碑+代理政策+二手残值行情）售后与配件知识库（故障对照+易损件型号+通用件替换）

访谈与验证 痛点是假设，访谈才是裁决

访谈对象
丘陵山区农机合作社理事长 3～5 人区县农机经销商 2～3 人农业农村局农机化科工作人员 2 人农机主机厂产品经理 2～3 人飞防队/托管服务组织负责人 2 人
验证指标
  • 单次购机决策从「凭感觉」变为有基准区间可依（访谈前后对比）
  • 补贴申报材料一次通过率（目标：免二次补正）
  • 作业行情被实际报价引用的次数（目标：月 50+）
  • 至少 3 个合作社或服务组织愿意按月回传作业量与价格数据
访谈问题清单（10）
  1. 最近一次买机（或帮社员买机）怎么定的机型？那笔账具体怎么算的？
  2. 你那片地最考验机器的是什么（坡度/地块大小/地头）？现有机型哪里最别扭？
  3. 补贴申请全流程哪一步最耗时间？资金实际多久到账？
  4. 作业报价怎么定的？有没有报亏了的一单，亏在哪？
  5. 农忙时怎么找活、怎么调度机手？微信群和电话各占多少？
  6. 最近一次趴窝是什么故障？从停机到复工花了多久，谁修的？
  7. 三包单据现在怎么记？厂家向你要过什么数据，你给了没有？
  8. 买过二手农机吗？怎么验机，吃没吃过亏？
  9. 如果有个网站能查作业价格和机型口碑，你凭什么信它的数？
  10. 你愿意把自己家的作业面积、价格、故障记录录上去吗？换什么你才愿意？
