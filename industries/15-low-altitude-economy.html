低空经济

智能装备

核心问题哪些低空作业已经能算过账并规模化，空域审批与运营合规怎么走通

这个产业赚的是「让天空变成运力和数据源」的钱：整机厂卖飞机、运营公司卖架次与数据、平台公司卖设施与航线；事卡在空域审批时限说不准、作业成本没有公认口径、eVTOL 取证周期以年计。

细分方向eVTOL工业无人机低空保障设施空管系统物流巡检应用
典型用户无人机运营公司行业客户(电力/测绘/应急)空管与审批部门整机制造商地方平台公司
重庆锚点峰飞航空西南总部落地两江新区，eVTOL 整机环节在渝落子（公开报道）梁平建设无人机制造产业园（公开目标产值 200 亿元），农用无人机保有量为全市最多2025 年重庆低空制造业产值 102 亿元（+22.9%），低空制造类企业 106 家、14 个市级试点区县（市产业地图口径）重庆已划设 47 块低空空域、92.78% 区域低空开放，空域资源供给靠前，但审批与运营合规流程仍在打通（市产业地图口径）

产业核心在 1000 米以下低空用无人机与 eVTOL 做物流、巡检、测绘、载人的运营生意，上游配套动力电池、飞控数据链、空管系统与起降设施。

S01

电力巡检投标前的作业账测算

运营负责人
触发事件

电网某地市公司发布输电线路无人机巡检标段，几天内要出报价

当前做法

翻旧项目台账估人天 → 打电话问同行报价口径 → 手工拆分机型折旧/电池损耗/人员差旅 → 拍一个略低于对手的价格

所需数据

杆塔数量与地形、机型与机巢配置、人工单价、电池循环损耗、空域报批成本

决策参数

单塔成本、返飞率、设备摊销年限、验收标准带来的复检成本

具体痛点

行业没有公认的作业成本口径，报高了丢标、报低了亏本；电池损耗和返飞率全凭感觉估

错误成本

报价失准：亏本中标一年白干，或整标丢失

现有替代

Excel 模板 + 同行电话打听 + 中标公告倒推价格

周网站可解证据中
无人机巡检报价电力巡检成本自动机场投标测算单塔成本
🖥 低空作业算账器：把机型摊销/电池损耗/人员/审批/保险拆成可调参数，输出单塔/单公里成本区间，并对照同行业已中标项目的公开口径
S02

飞行活动申请与计划报批

运营负责人
触发事件

《无人驾驶航空器飞行管理暂行条例》施行后，管制空域内的行业作业每次都要提前提交飞行活动申请

当前做法

登录 UOM 平台填申请 → 等审核 → 涉管制空域再打电话协调军民航 → 被要求补材料时重新走一轮

所需数据

作业时间窗口、空域类别、机型与架次、操控员执照信息、作业内容说明

决策参数

申请提前量、审批时限、是否涉管制空域、临时增补架次的可行性

具体痛点

各地审核口径与时限不一，临时加飞常赶不上申请周期；驳回原因往往只有一句「不符合要求」

错误成本

任务延期违约，或者顶风「黑飞」面临处罚与吊证

现有替代

本地熟人问窗口口径 + 攒「一次申请多架次」的经验

周部分可解证据高
空域申请UOM 平台飞行计划报备管制空域黑飞处罚
🖥 网站做「地区×机型×业务类型」的申请路径库：材料清单、平均时限、驳回案例与申诉写法；正式审批仍必须走官方平台
S03

作业前空域与限制区查询

作业飞手
触发事件

早上接到任务单，要去一个没去过的县区做河道巡查，先要确认那里能不能飞

当前做法

打开官方 App 查适飞空域 → 再翻地图找机场净空区、军事设施、临时管制公告 → 多个图层对不齐就打电话问当地

所需数据

作业点坐标、任务高度、机型类别、当日临时限制公告

决策参数

适飞空域边界、净空保护区范围、临时禁飞通告、申请豁免路径

具体痛点

行业级中型机超出「真高 120 米以下免申请」的范围，限制图层分散在不同系统，没有一份权威汇总

错误成本

误入管制空域被处罚、设备暂扣，项目直接黄掉

现有替代

多个 App 交叉对照 + 打电话找当地公安/空管确认

日部分可解证据高
适飞空域查询禁飞区净空保护区无人机限高飞行管制
🖥 网站做「任务→需查哪些图层」的导航器（标注官方数据源与更新日期），并给中型机叠加军民航限制的申请路径提示；权威边界以官方系统为准
S04

任务当天的 go/no-go 气象决策

作业飞手
触发事件

任务窗口只有当天下午，现场阵风看着不小，通用气象数据给不出飞行级别的判断

当前做法

看通用气象 App → 放飞试探几分钟后拉回 → 问老飞手「这种风你飞不飞」→ 凭经验拍板

所需数据

现场风速与阵风实测、温度、降水概率、峡谷/江面地形风、电池温度

决策参数

机型抗风等级、载荷迎风面、续航随温度的衰减、返航电量余量

具体痛点

手册抗风等级是理想工况测的，江面峡谷阵风瞬变，go/no-go 没有判据，风险全压在飞手个人身上

错误成本

炸机损失整机与载荷，或过度保守天天不飞、项目交付延期

现有替代

便携风速仪 + 老师傅经验 + 试飞试探

日必须线下证据高
无人机抗风等级阵风气象包线go no-go低温续航
⛔ 线下原因：现场阵风与地形风必须实测、决策责任在飞手本人——网站只能做机型气象包线速查与历史风况统计参考
S05

电池衰减与退役判据

作业飞手
触发事件

机队某批电池最近掉电明显变快，担心哪一块在空中突然掉链子

当前做法

翻智能电池 App 看循环次数 → 对比满电压降 → 鼓包目检 → 凭手感决定「再用一段时间」

所需数据

循环次数、内阻/压降记录、存放温度历史、外观检查结果

决策参数

容量保持率阈值、内阻增长斜率、任务风险等级、换电成本

具体痛点

没有行业公认的退役判据，早换成本高、晚换炸机险；低空物流的高频飞行把这个矛盾放大

错误成本

空中断电炸机损失整机，或提前报废整批电池多花数万元

现有替代

按循环次数一刀切 + 厂家售后寄检（周期长）

周部分可解证据中
无人机电池寿命循环次数电池鼓包SOH换电
🖥 网站汇总各机型电池的公开衰减规律与运营商退役判据（循环数/内阻阈值双轨），形成自查清单；实测仍要靠自家电池日志
S06

巡检成果缺陷判定与验收扯皮

甲方项目工程师
触发事件

无人机巡检了几百基塔，AI 判读报出一堆疑似缺陷，班组照单消缺后发现相当部分是误报

当前做法

AI 初判 → 人工逐张复核影像 → 和运营公司争执误报漏报责任 → 合同没写清楚，最后不了了之

所需数据

可见光/红外原始影像、AI 识别结果、人工复核记录、杆塔台账

决策参数

识别准确率口径、缺陷等级划分、复检抽样规则、漏判责任归属

具体痛点

AI 判读率各家宣传口径不一，漏判一个真实缺陷发热点，追责时说不清是模型、飞手还是天气的锅

错误成本

漏判真实缺陷演变成线路故障停电，事故追责追到甲方头上

现有替代

要求双飞双检（成本翻倍）+ 关键塔位人工登塔复核

月网站可解证据中
巡检缺陷判读AI 识别误报红外测温验收标准输电巡检
🖥 「缺陷类型×影像样例×判读口径」公开样例库 + 验收合同条款模板（识别率定义、抽样复检规则、漏判责任条款）
S07

人工巡检与自动机场的路线论证

甲方项目工程师
触发事件

上级要求对山区输电线路巡检做机械化换人论证，限期给出两条路线的对比方案

当前做法

让几家厂商和运营公司各报方案 → 各说各好 → 自己用 Excel 拼人工日单价、机巢造价、覆盖范围 → 报告口径被审计质疑

所需数据

线路长度与塔基数、地形与交通条件、人工巡检单价、机巢与航线造价

决策参数

全周期成本、覆盖盲区、恶劣天气可用天数、缺陷检出率差异、作业安全风险

具体痛点

「机械化换人」缺中立的对比口径，厂商方案都高估自己，论证报告经不起审计与事后复盘

错误成本

路线选错，几百万设备闲置或巡检质量下滑被通报

现有替代

请设计院出咨询报告（周期长、对新型机巢也未必熟）

季网站可解证据中
无人机自动机场机巢机械化换人巡检方案对比电网无人化
🖥 在线对比测算器：统一口径拆解两条路线的全周期成本与检出能力，附公开落地项目的运行情况档案
S08

航测成果精度不达标返工定责

决策参数

具体痛点

规章条文分散且术语绕，培训机构的解答天然带销售倾向；飞错类别被查，个人与公司双罚

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 算账工具：把「一架无人机一年能赚多少钱」拆成可调的成本模型（机型摊销/电池损耗/保险/审批成本），支撑投标与立项
  • 空域与审批导航：各地飞行申请口径、材料清单、驳回案例与加急路径的结构化档案
  • 资质证照导航：业务类型 × 执照/运营合格证/测绘资质/保险的映射查询
  • 参数归一与选型：整机/电池/平台参数统一到相同工况口径，标注标称与实测差异
  • 城市政策与补贴对比：补贴口径、试点资质、空域开放度横向对比，标注文件出处与日期
  • 公开里程碑与事故案例库：取证进度、航线开通、事故调查结论的结构化跟踪

🚧 必须线下 / 网站只能辅助

  • 实飞测试与现场气象判断：go/no-go 依赖现场风况与机型状态，网站只能给包线参考
  • 军民航空域协调与应急加急：值班体系内的实时联动，责任链条在线下
  • 适航审定的符合性验证与局方沟通：试验、审核、专用条件谈判必须线下
  • 炸机现场勘查与保险定损：残骸、日志、现场取证在线下完成
  • 起降点的土地/消防/物业谈判：商务关系与现场勘测不可在线替代
  • 大客户关系与招投标的关系环节：商务决策在线下会议室完成

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

运营公司带着「这个单子接不接、怎么报价」来 → 用算账器出成本与报价区间 → 查空域审批路径与政策补贴 → 回传自己的真实项目成本单 → 案例越多行业基准价越准，后来者依赖存量数据

需要建设的数据表
  • 作业成本要素库（机型/电池损耗/人员/保险/审批成本/充换电）
  • 空域审批路径库（地区/空域类别/业务类型/材料清单/平均时限/驳回原因）
  • 城市政策库（补贴口径/试点资质/空域划设/适用对象）
  • 机型参数库（标称工况/实测修正/载荷适配）
  • 项目与事故案例库（行业/地形/合同额区间/结论）
信任来源
  • 成本模型字段全部公开假设与出处，用户可改参数重算
  • 审批时限与驳回案例标注地区与日期，注明为用户回传口径
  • 机型参数区分「厂商标称」与「用户实测」，双轨展示
  • 案例只收有公开出处或用户授权的事实，标注来源与日期
可做产品形态
低空作业算账器（投标/立项成本模型 + 全周期对比测算）空域审批与合规导航站（地区×机型×业务类型的申请路径库）整机/电池/平台参数归一选型库（标称 vs 实测双轨）城市政策与补贴对比数据库（招商与选址决策用）「要做什么业务需要什么证」资质向导

访谈对象
持证无人机运营公司创始人/运营负责人 3~5 人电网/测绘系统甲方项目工程师 2~3 人地方低空管理平台或空管协调岗位人员 1~2 人eVTOL 整机厂适航审定工程师 1~2 人跟踪低空赛道的投资经理 1~2 人
验证指标
  • 算账器使用深度：月 30+ 个投标/立项项目用它出报价
  • 审批路径命中率：按导航提交的申请首次通过率明显高于用户自述历史水平
  • 数据回传率：运营公司回传真实项目成本单的比例（目标 >10%）
  • 付费验证：至少 3 家运营公司/平台公司为算账报告或审批档案付费
访谈问题清单（10）
  1. 最近一次投标报价是怎么算出来的？哪些成本项你最没把握？
  2. 空域申请平均要几天？被驳回过吗，原因是什么？
  3. 你的机队一年实际飞行小时多少？电池多久换一批，判据是什么？
  4. 甲方验收巡检成果时，争议最多的是哪一条？
  5. 有没有算过单票/单塔/单公里的真实成本？和报价差多少？
  6. 保险买了吗？出过险吗，理赔过程怎么样？
  7. 政府补贴拿到手多少？申报花了多少人力？
  8. 你会相信一个网站给出的行业基准价吗？什么条件下愿意回传自己的数据？
  9. 招飞手时最看重什么？市场上怎么判断一个飞手的真实水平？
  10. 如果只解决一个痛点，你选审批、算账还是找客户？
