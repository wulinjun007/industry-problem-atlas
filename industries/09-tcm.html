09

现代中药

生物医药

核心问题从种植到饮片的质量一致性为什么难控制，溯源体系能不能真落地

这个产业赚「从土里到处方」的加工与信任溢价；种植户、采购员、质量负责人和注册专员在干活，事卡在质量一致性说不清——农残硫熏超标、批间色泽不一、溯源码背后没数据。

细分方向中药饮片配方颗粒中成药道地药材中医器械
典型用户中药企业注册专员饮片厂质量负责人临床与药店渠道药材种植户科研院所
重庆锚点国药太极涪陵制药厂2026年6月获评全球中药行业首家「灯塔工厂」，重庆因此握有中药智能制造的标杆锚点南川中医药科技产业园落地华润三九等49个项目，2025年南川中医药全产业链产值突破60亿元石柱黄连产量占全国约六成、黄水市场交易量占全国九成以上，全市青蒿约8.5万亩居全国首位涪陵布局林下仿野生中药材约19万亩，道地药材种植是重庆生物医药集群的上游底座

产业核心把道地药材种出来、按药典炮制成饮片、做成配方颗粒和中成药卖进医院与药店，赚「从一株草到一味药」的炮制、合规与品牌溢价。

产业链地图

上游原料 / 部件 / 设备

道地药材种植

黄连、青蒿、玄参等药材的规模化与仿野生种植、GAP基地建设

种植户、合作社、国药太极/九州通等企业自建共建基地农户散种为主，用药用肥无记录，质量一致性从源头就是散的
种苗与农资

种苗繁育、肥料与农药供应

种苗商、农资店种苗商按卖苗逻辑推荐品种，是跟风种植的放大器
产地初加工与趁鲜切片

净选、干燥、切片、防虫防霉处理

产地加工户、合作社、饮片厂产地车间熏硫、抢青等原始加工习惯仍在，是二氧化硫超标与性状不合格的主要来源
中药材市场与流通

亳州/安国/玉林等市场集散、经纪人居间撮合

亳州药市、安国药市、产地经纪人外调货充本地货常见，价格口径混乱，验货靠眼看嘴尝

中游制造 / 集成 / 流通

中药饮片炮制

净制切制炙煅蒸煮，产出临床配方用饮片

全国数千家饮片厂，中小厂占多数GMP要求全套记录，小厂纸面合规与真实操作两张皮
配方颗粒生产

单味饮片提取浓缩制粒，供中医处方调剂

头部配方颗粒企业，国标与省标品种备案并行跨省备案口径不一，投料药材的基原与一致性难自证
中成药制造

经典方与创新方的成药规模化生产

国药太极等药企（涪陵、南川承载）批间一致性依赖原料稳定；经典名方二次开发与创新药少
中医器械

针灸针、艾灸、拔罐、熏蒸与贴敷类产品

医疗器械厂与消字号产品企业分类界定模糊，功效宣称的边界靠踩线

下游应用 / 服务 / 终端

医疗机构中药房

饮片处方调配、代煎、配方颗粒调剂

中医医院、综合医院中医科、代煎中心验收退贷靠药师经验，质量争议在验收单上现场解决
零售药店与电商

饮片柜、配方颗粒、药食同源产品零售

连锁药店、医药电商平台集采与医保支付口径直接决定品类与毛利结构
中医诊疗服务

中医门诊与住院处方对饮片颗粒的真实消化

各级中医医疗机构处方量是上游一切产能的最终出口
大健康与出口

代茶饮、药膳、提取物与药材出口

大健康品牌、外贸企业药食边界与海外农残标准是两道绕不开的合规坎

S01

药典升版后的全品种质量标准变更

饮片厂质量负责人
触发事件

药典新版本或增补本发布，禁用农药残留等要求扩大到更多品种，局里通知限期执行

当前做法

把新旧版药典逐页对照 → 列出受影响品种清单 → 改检验SOP → 做方法验证 → 更新备案与标签文件

所需数据

新旧药典原文、在产品种清单、现行SOP与检验方法

决策参数

指标增删、方法变化、方法验证工作量、生效日期

具体痛点

全品种比对靠人工翻书，一个指标变化牵动检验方法、SOP、包装标签多条线；漏一项就是检验缺项，飞检直接开缺陷

错误成本

批次放行延误数周，飞检缺陷公示影响客户目录资格

现有替代

打印对照表贴墙 + 同行微信群口口相传

年网站可解证据高
药典2020版农药残留33项质量标准变更方法验证
🖥 新旧药典指标逐条对照库 + 按自家品种清单一键生成变更任务与截止日期
S02

配方颗粒跨省备案逐省闯关

中药企业注册专员
触发事件

销售要进一个新省份，省标品种必须先在该省药监完成备案

当前做法

查目标省药监公告 → 准备标准复核材料 → 线上平台填报 → 排队等回执 → 被退回补正再来一轮

所需数据

国标/省标品种清单、各省备案平台材料要求、标准复印件

决策参数

已备案品种数、省标与国标差异、备案周期、退回率

具体痛点

各省备案要求不汇总、口径常变，同一份材料A省能过B省退回；全靠专员个人经验沉淀在脑子里

错误成本

单省市场准入晚一季度，销售指标落空

现有替代

靠备案代理传话 + 专员在同行群里挨个问

月网站可解证据高
配方颗粒备案省标品种跨省销售标准复核
🖥 各省备案要求与典型退回理由对照库，按品种生成材料清单与进度看板
S03

经典名方立项前查谁已经报了

中药研发工程师
触发事件

公司决定立项3.1类中药经典名方，领导要一张「目录里哪些品种还没人申报」的表

当前做法

上CDE受理查询逐条翻 → 手工Excel记录各家申报与审评状态 → 判断剩余空白品种 → 写立项报告

所需数据

古代经典名方目录、CDE受理公示、自家品种储备

决策参数

已申报家数、审评进度、原料药材被垄断情况、市场容量

具体痛点

受理数据要逐月手工盯，公示还有滞后；「没人报」可能是「报了没做成」，空白判断错一次就是几百万研发投入打水漂

错误成本

撞车立项，研发投入沉没且错过其他品种窗口

现有替代

买商业医药数据库（年费数万）或听CRO转述

月网站可解证据高
经典名方目录3.1类中药CDE受理立项调研
🖥 按经典名方品种聚合各家受理与审评状态的追踪表，附变化订阅提醒
S04

行情暴涨下的囤货拍板

中药材采购员
触发事件

当归、党参等大宗品种价格连涨数月，老板要求今天给结论：现在进还是等产新

当前做法

打给产地经纪人问价 → 刷行情网站 → 托人摸亳州安国市场库存 → 凭经验拍板

所需数据

各市场报价、产地反馈、库存与资金动向传闻

决策参数

产新时间、在地面积、资本介入迹象、企业安全库存天数

具体痛点

报价有水分、库存全靠传闻，同一天两个市场价差能到两成；买在高点全年利润被吃掉，不买产线随时断料

错误成本

一批原料买在高点，采购成本超预算数成

现有替代

经纪人人脉 + 微信群小道消息，交叉验证全靠胆识

日部分可解证据高
中药材价格当归行情囤货亳州市场
🖥 网站做同品种多市场价格对照与产新日历（口径透明可回溯），但真实库存与资金动向仍要线下打听
S05

溯源码贴上去了，扫开却没数据

饮片厂质量负责人
触发事件

医院和连锁客户要求饮片带追溯码，监管也在推全链条追溯

当前做法

采购一套溯源系统 → 给批次赋码 → 打印贴签 → 客户扫码只看到品种和批号两行字 → 从此没人再扫

所需数据

批生产记录、进货查验记录、检验报告、上游农户信息

决策参数

码内信息深度、上游农事数据可得性、系统对接成本

具体痛点

上游是分散农户，种植用药数据根本收不上来；码成了应付检查的贴纸，质量一致性还是只能靠检验报告硬扛，出了事故链条一查就断

错误成本

质量事故时溯源链条断裂，整批召回并丢掉客户目录资格

现有替代

Excel台账 + 纸质记录应付检查

周部分可解证据中
中药材追溯溯源码批次追溯进货查验
🖥 网站做「码后真有货」的公开示范档案（检验报告+产地档案可查），倒逼溯源码里有内容；农户端数据采集仍要靠线下组织
S06

进货验收检出禁用农药超标

QC检验员
触发事件

一批当归进厂，委外做禁用农药残留检测，报告回来甲拌磷超标

当前做法

通知暂缓入库 → 留样复检 → 启动供应商调查 → 退货或销毁 → 更新该供应商风险评估等级

所需数据

检验报告、留样、供应商协议、产地来源信息

决策参数

限量判定、复检规则、送样与到货一致性、供应商分级标准

具体痛点

33项农残一轮送检数千元、周期一两周，小厂送不起全检只能抽检赌运气；等结果出来货在库里已经躺了两周

错误成本

整批退货数万元起，若漏检流入临床就是药害事件

现有替代

凭产地证明 + 抽一定比例送检

周必须线下证据高
禁用农药甲拌磷农残检测进货检验
⛔ 线下原因：检测必须物理送样到实验室，复检与留样管理不可在线替代——网站只能做高风险品种/产地的风险提示与检测机构比价
S07

流转了地，种什么药材不踩周期

药材种植户
触发事件

手里攒了几十亩地想种药材，亲眼见过白及从百元跌到几钱一斤的惨状

当前做法

看邻居种什么 → 问收购商 → 刷短视频上的「种植致富」 → 找种苗商咨询（种苗商说什么赚钱）

所需数据

各品种当年价格、种苗价格、生长周期、自家地块海拔土壤

决策参数

生长周期长短、当前在地面积、产新预测、订单收购可能性

具体痛点

信息源全是利益相关方，种苗商盼你买苗；黄连五年起收，等你采收时价格早已翻脸，跟风就是一个周期白干

错误成本

一个种植周期（3～6年）的投入血本无归

现有替代

跟合作社或龙头企业订单种植（订单本身也不稳定）

年部分可解证据中
黄连种植周期白及价格药材种植种苗选购
🖥 网站做品种周期档案（历史价格+在地面积+产新时间）拆穿致富神话；最终决策仍受制于自家地块与订单资源
S08

GAP检查前连夜补农事记录

药材种植户
触发事件

龙头企业的GAP基地年度检查下周到，检查表要求全年施肥打药记录

当前做法

翻找农药购买单据 → 按表格格式补写全年农事记录 → 签字确认 → 祈祷用药名单能对上允许清单

所需数据

农药购买单据、施肥习惯记忆、检查要点表

决策参数

用药是否在允许清单、安全间隔期、采收时间、记录前后一致性

具体痛点

农户凭经验用药没人当场记，检查前集中补记录是行业公开秘密；一旦笔迹或逻辑对不上直接判不符合

错误成本

基地资格被摘，订单收购价与销路一起没了

现有替代

基地管理员代记（依旧是事后补）

年部分可解证据中
GAP基地农事记录中药材种植检查整改
🖥 极简拍照式农事记录工具 + 打药前实时核对禁限用清单；习惯养成要靠龙头企业驻点督导
S09

打药前查这个药能不能用

药材种植户
触发事件

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 标准与法规对照：药典新旧版差异、各省配方颗粒备案口径、趁鲜加工目录的合并查询与任务生成
  • 行情与产地档案：同品种多市场价格对照、产新日历、高风险产地与风险指标提示
  • 申报与竞争情报：经典名方受理进度聚合、说明书修订公告按文号匹配、器械分类界定速查
  • 鉴别与基原知识库：正品-混淆品-劣品对照图谱、硫熏风险档案、种植用药禁限速查
  • 溯源示范档案：让扫码后真能看到检验报告与产地农事，把溯源从贴纸变成质量一致性的证据链

🚧 必须线下 / 网站只能辅助

  • 农残、重金属、二氧化硫等检验：必须物理送样进实验室，在线工具只能做风险提示与机构比价
  • 产地审计与炮制带教：货源真实性和火候经验要眼见手传，视频与文档替代不了
  • GMP飞行检查与自查整改：对象是本厂的记录与现场，网站只能给要点清单与处罚案例库
  • 种植端农事执行：记录工具能上云，但让农户真种真记要靠龙头企业驻点与订单绑定
  • 渠道信任与药事决策：进院、集采、药事会拍板依赖线下关系与实物试用

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

质量负责人/采购员带着「这批货敢不敢收、这个标准变了没有」来 → 查标准对照与产地风险档案 → 生成进货查验或备案任务清单 → 把自家检验结论与成交价回传充实档案 → 回传越多档案越准，后来者离不开存量档案

需要建设的数据表
  • 药材品种库（基原/主产地/产新期/高风险指标）
  • 标准差异库（药典版本/指标/方法/生效日期）
  • 行情库（品种/市场/价格/日期/采集口径）
  • 申报库（经典名方与配方颗粒受理/审评状态）
  • 供应商与产地档案（审计记录/农事记录/检验结论）
信任来源
  • 每条标准标注药典原文表述与生效日期
  • 行情数据标注市场名称与采集口径，不同口径不混排
  • 公告类信息给出文件号与日期，可回溯原文
  • 供应商与产地档案区分「自报」与「核验」两级，界面颜色区分
可做产品形态
标准法规对照导航站（按品种一键生成药典/备案/目录的合规任务清单）中药材行情与产地风险档案库（多市场价格对照+产新日历+风险指标）经典名方与配方颗粒申报情报站（受理进度聚合视图+订阅提醒）饮片鉴别图谱与基原混淆品对照库（含典型争议案例）扫码可验的溯源示范档案（检验报告+产地档案公开可查）

访谈与验证 痛点是假设，访谈才是裁决

访谈对象
饮片厂质量负责人 3～5 人中成药/配方颗粒企业注册专员 2～3 人中药材采购员 2～3 人产地合作社带头人 2 人三甲医院中药房药师 1～2 人
验证指标
  • 查一项新旧药典差异的耗时：从半天翻书降到 10 分钟内
  • 采购决策引用行情与产地档案的次数（目标：月 30+ 次）
  • 标准变更/备案任务清单生成量（目标：上线 3 个月 100+ 份）
  • 付费验证：至少 3 家饮片厂/药企为标准对照或申报情报付费
访谈问题清单（10）
  1. 最近一次因农残或二氧化硫超标退货是什么品种？损失最后谁承担？
  2. 你们的追溯码扫出来能看到什么？有客户真的扫过吗？
  3. 药典升版后你们用了多久完成标准变更？卡在哪一步？
  4. 配方颗粒跨省备案，哪个省最难？被退回的理由是什么？
  5. 决定囤货那一刻，你看哪个信息源？信它几成？
  6. 经典名方立项时，你怎么查别人申报到哪了？花了多久？
  7. 医院验收退回过什么货？药师下结论的依据是什么？
  8. 基地农事记录是当场记的还是检查前补的？差多少？
  9. 哪些品种的混淆品和掺伪最让你头疼？你是怎么发现的？
  10. 如果网站能按你的文号清单自动匹配说明书修订任务，你愿意按什么方式付费？
