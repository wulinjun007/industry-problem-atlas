13

前沿新材料

先进材料

核心问题技术究竟成熟到什么程度，能不能稳定量产和商用

这个产业赚的是「把实验室新材料变成工业品」的钱；材料研发和放大工程师在干活，事卡在中试放大后批次不一致、下游不敢用、第一份订单难拿。

细分方向气凝胶石墨烯MOF等新型材料
典型用户材料企业研发人员应用企业产业研究机构检测认证机构产业投资机构
重庆锚点重庆鑫景特种玻璃：华为昆仑玻璃与 C919 航空玻璃原片供应商（两江新区）涪陵布局 MOFs 材料方向，大渡口宝武特冶深耕特种冶金材料2025 年重庆规上新材料企业 242 家、产值 1612 亿元（统计局口径），新材料是全市先进材料集群主攻方向

产业核心把实验室里的新型材料（气凝胶、石墨烯、MOF 等）推进到能量产、能商用的工业材料，赚「从论文到产品」的工程化溢价。

产业链地图

上游原料 / 部件 / 设备

高纯原料与前驱体

提供硅源、金属盐、石墨原料、表面活性剂等基础原料

无机化工企业、试剂供应商纯度与批次稳定性直接决定下游放大成败
专用装备

CVD 炉、喷雾干燥、超临界干燥釜、烧结炉等专用设备

真空/窑炉设备厂、进口设备代理进口设备贵且交期长，国产设备工艺匹配度要反复调
检测认证机构

成分、纯度、比表面积、热导率等性能检测

国家新材料测试评价平台、高校分析测试中心新型材料往往没有国标，检测方法各家用各家的

中游制造 / 集成 / 流通

材料合成与制备

气凝胶毡/板、石墨烯粉体/浆料、MOF 粉体的合成

前沿材料创业公司、大厂新材料事业部实验室克级到产线吨级是最大的坎
改性与复配

分散、表面修饰、与基体材料复合成可用形态

改性工厂、复材加工企业纳米材料分散不均是性能翻车的头号原因
制品加工

把材料做成保温毯、涂层、电极片、吸附模块等制品

保温材料厂、涂层加工厂、电池材料厂制品环节决定客户拿到手的是材料还是商品

下游应用 / 服务 / 终端

工业节能与保温

管道保温、窑炉节能、LNG/冷链设备用气凝胶

石化/电力工程公司、节能服务商要按工程项目投标，账期长但单子大
电子与新能源

导热膜、导电添加剂、传感器敏感材料

消费电子供应链、电池厂认证周期长，进一个合格供应商名录要 1～2 年
环保与吸附分离

MOF/多孔材料用于气体分离、水处理、防潮

环保工程公司、气体企业客户要的不是材料是解决方案，得捆绑工程服务
产业研究与投资

技术成熟度评估、赛道判断、标的尽调

券商研究所、VC/PE、政府产业基金缺中立的技术成熟度证据链，容易被 PPT 项目误导

用户角色地图 谁在干活、被考核什么、卡在哪

产业化研发工程师
是谁

在材料公司负责把小试配方推进到中试和量产工艺

被考核

放大后批次合格率、成本达标时间

用什么干活

实验记录本、DOE 软件、小试/中试设备、文献数据库

最常见卡点

小试性能很好，一放大性能就掉，不知道变量藏在哪

应用开发工程师
是谁

在下游应用企业（电子/电池/节能工程）评估和导入新材料

被考核

新材料导入项目数、验证通过率

用什么干活

应用测试台架、可靠性试验标准、供应商样品

最常见卡点

供应商给的性能表都是「最佳值」，自己要花几周重测

放大生产负责人
是谁

管中试线/量产线的工艺稳定、良率与安全

被考核

良率、单位成本、安全事故为零

用什么干活

DCS 系统、SPC 控制图、设备点检表

最常见卡点

纳米粉体的团聚、粉尘防爆、批次追溯全靠自己摸索

销售/BD 负责人
是谁

在材料公司负责找第一批愿意试用的下游客户

被考核

新客户验证进度、回款

用什么干活

CRM、展会名录、检测报告

最常见卡点

客户要求「有同行用过才敢试」，但第一批同行从哪来

应用端采购工程师
是谁

在下游企业负责新材料供应商寻源与比价

被考核

供应保障、降本幅度、质量事故次数

用什么干活

1688、行业展会、供应商问卷

最常见卡点

「石墨烯含量 3%」这种宣传没法核实，踩过亏才知道深浅

检测与标准工程师
是谁

在材料公司或第三方机构做检测方案

被考核

检测周期、报告被客户认可的比率

用什么干活

国标/行标库、检测机构比价表

最常见卡点

新材没有国标，同一份样品两家机构测出两个结果

投资/产业研究员
是谁

在基金、券商或政府平台评估前沿材料项目的成熟度

被考核

判断准确率、投后项目存活率

用什么干活

论文库、专利库、访谈纪要

最常见卡点

分不清「论文性能」和「可售产品」之间差几个 TRL 等级

真实工作场景 每张卡片：什么触发 → 现在怎么做 → 卡在哪 → 值不值得数字化

S01

为新项目初筛隔热材料体系

应用开发工程师
触发事件

新产品要求隔热层厚度减半，现有传统保温材料达不到

当前做法

搜论文和公众号文章 → 找 3～5 家供应商要样品和性能表 → 自己搭台架重测 → 写对比报告

所需数据

工况温度/湿度/空间限制、供应商性能表、样品

决策参数

热导率、使用温度上限、机械强度、阻燃等级、单价

具体痛点

性能表全是各自实验室最佳值，测试方法不统一，比来比去没法下结论；重测一轮 2～4 周

错误成本

选错材料，整机项目返工，损失数十万

现有替代

展会扫名片 + 熟人推荐供应商，Excel 手工对比

季网站可解证据高
气凝胶导热系数保温材料对比纳米隔热选型
🖥 按统一测试方法归一的材料参数库 + 工况选型器（输温度/空间/预算出候选名单）
S02

判断一篇新技术论文离量产还有多远

投资/产业研究员
触发事件

老板/基金合伙人丢来一篇 Nature 子刊论文，问这东西能不能投

当前做法

读论文看性能 → 查专利归属 → 搜团队背景 → 找懂行的朋友电话求证 → 拍脑袋给结论

所需数据

论文原文、专利检索、团队履历

决策参数

制备路线是否可放大、原料成本、有无中试数据、TRL 等级

具体痛点

论文只报最佳样品性能；克级成本和吨级成本差两个数量级，公开信息推不出来

错误成本

投错项目数百万打水漂，或错过真标的

现有替代

熟人专家网络付费咨询（专家费 3000+/小时）

月部分可解证据中
TRL 技术成熟度中试放大技术评估石墨烯量产
🖥 网站可给「论文→量产距离」的评估框架与公开案例对照库；关键判断仍需线下访谈工艺人员
S03

气凝胶毡采购比价，报价差 3 倍

应用端采购工程师
触发事件

工程项目预算审核，要求说明为什么选贵的这家气凝胶供应商

当前做法

发询价函给 5+ 家 → 收到报价和性能表 → 试图比单价 → 发现密度/厚度/热导率各不相同没法直接比

所需数据

各家的密度、厚度、热导率、使用温度、寿命承诺

决策参数

单位面积热阻成本、使用寿命、防火等级、供货稳定性

具体痛点

没有「每单位热阻多少钱」的统一口径，比价变成玄学；低价中标后寿命缩水没人管

错误成本

采购价虚高 20～50%，或低价料两年就粉化

现有替代

Excel 手算换算 + 供应商口头承诺

月网站可解证据中
气凝胶毡价格保温材料报价采购比价热阻成本
🖥 标准化比价工具：录入各规格自动换算成单位热阻成本 + 寿命修正系数
S04

中试放大后性能掉一半

产业化研发工程师
触发事件

小试 10 批全达标，中试线 100L 反应釜做出来的性能只有小试六成

当前做法

排查温度场/搅拌/投料速度 → 凭经验调参数 → 一批一批试错，每批一周

所需数据

小试/中试完整工艺记录、设备规格、在线监测数据

决策参数

混合均匀度、温度均匀性、投料速率、陈化时间

具体痛点

放大不是线性的，公开文献给不了你这条产线的修正系数；每轮试错烧原料和时间

错误成本

放大周期拖长 6～12 个月，融资节点错过

现有替代

请高校教授「把脉」+ 全靠自己试错

季必须线下证据高
中试放大工艺放大批次一致性DOE
⛔ 线下原因：放大依赖本产线设备与物料的实测数据，别人替代不了——网站只能做放大案例库和排查清单参考
S05

向大客户证明批次一致性

销售/BD 负责人
触发事件

电池厂/电子厂要做合格供应商审核，要求提供近 12 个月批次数据

当前做法

翻生产记录整理各批次 COA → 做成 PPT → 现场审核被追问异常批次原因

所需数据

逐批次检测报告、留样、异常处理记录

决策参数

关键指标的 CPK、批间偏差、可追溯性

具体痛点

小厂记录不全，临时补数据经不起追问；客户要的是体系证据不是一张漂亮报表

错误成本

审核不过，丢失进大供应链的机会，一年白干

现有替代

请咨询公司突击做体系文件（几万到十几万）

季部分可解证据中
批次一致性COA供应商审核CPK
🖥 网站提供一致性数据模板与审核应答清单；真实数据必须来自自家 MES/LIMS
S06

石墨烯浆料分散总是团聚

产业化研发工程师
触发事件

换成新批次石墨烯粉体后，浆料粘度和沉降异常

当前做法

调超声时间/分散剂比例 → 做粒度分布和电导率测试 → 小批量试到合格为止

所需数据

粉体比表面积/层数表征、分散剂体系、工艺参数

决策参数

Zeta 电位、粒度分布 D50、粘度、静置沉降率

具体痛点

每批粉体特性不同，工艺窗口要重摸；原料厂不给完整的表征数据

错误成本

一批浆料报废数千到数万元

现有替代

锁定单一供应商 + 到货全检（成本高）

周必须线下证据高
石墨烯分散浆料团聚Zeta电位分散剂
⛔ 线下原因：分散工艺强依赖本厂设备与配方体系——网站只能汇总公开的分散工艺路线与故障树
S07

MOF 材料水稳定性不达标

产业化研发工程师
触发事件

客户要求在 80% 湿度环境下循环使用 100 次性能不衰减

当前做法

查文献找水稳定框架 → 换金属节点/配体 → 重复吸脱附循环测试，每轮 1～2 周

所需数据

目标 MOF 结构、应用工况（湿度/温度/气氛）、循环测试数据

决策参数

循环后保持率、成本增量、合成步骤数

具体痛点

论文里的稳定化方案往往只对特定体系有效，且不公开完整工艺

错误成本

项目验收失败，研发投入沉没

现有替代

与高校课题组合作开发（周期长、知识产权纠缠）

月部分可解证据中
MOF水稳定性循环吸附框架材料湿稳定性
🖥 网站可建「稳定性改造路线对比库」（公开专利+论文数据结构化）；实验仍要自己做
S08

申报新材料首批次应用保险补贴

销售/BD 负责人
触发事件

新材料的第一个大订单，客户要求风险兜底，想起有政策性保险

当前做法

搜当地工信/金融办文件 → 打电话问经办处 → 准备材料证明「首批次」资质 → 找承保机构谈

所需数据

产品先进性证明、检测报告、用户应用报告、营业执照经营范围

决策参数

保费比例、补贴比例、认定门槛、办理周期

具体痛点

政策散在各委办局，经办口径不一，材料来回补，一单拖 3～6 个月

错误成本

错过补贴窗口或投标保证金压力转嫁

现有替代

找政策代办中介（收服务费）

年网站可解证据高
首批次保险新材料补贴政策申报工信部
🖥 政策申报导航：按地区/材料类别匹配可申报政策 + 材料清单 + 经办口径实录
S09

寻找第一个愿意试用的下游客户

销售/BD 负责人
触发事件

中试线跑通，账上现金只够烧 12 个月，必须尽快开出第一单

当前做法

列目标行业 → 展会扫馆 → 托人引荐 → 免费寄样 → 等测试结果石沉大海

所需数据

目标行业名录、关键决策人、材料对位的应用痛点

决策参数

客户验证周期、替换动力强度、测试成本、决策链

具体痛点

客户验证一个新材料的成本比自己想象高，没人为「试试」买单；不知道谁正在主动找替代材料

错误成本

第一单晚到一季度，公司可能死掉

现有替代

参加行业展会 + 低价甚至免费送样

周部分可解证据中
新材料应用客户验证送样第一桶金
🖥 网站做「应用需求—材料能力」双向登记与匹配，降低互相找不到的成本；信任建立仍要线下
S10

核实供应商「石墨烯含量」宣传

应用端采购工程师
触发事件

老板要求把「石墨烯加热膜」成本降下来，找了几家便宜一半的供应商

当前做法

要第三方检测报告 → 发现只测了「碳含量」→ 自己送检拉曼/SEM → 和供应商扯皮

所需数据

供应商宣传页、检测报告、样品

决策参数

层数/缺陷度（拉曼 ID/IG）、单层率、导电性达成率

具体痛点

「含石墨烯」和「是石墨烯」之间有巨大灰色地带，检测费和时间都要自己出

错误成本

买到「炭黑+ wax」级别的假货，产品投诉召回

现有替代

只买上市公司/老牌厂产品（贵）

月网站可解证据高
石墨烯真伪拉曼检测单层率供应商核实
🖥 真伪鉴别指南 + 各家检测方法/报告编号公示 + 供应商宣传与实测数据的对照档案
S11

送检时不知道按什么标准

检测与标准工程师
触发事件

客户合同里写「性能按相关标准检测」，但这类新材料没有国标

当前做法

查国标行标库 → 找最接近的通用标准 → 和客户谈判适用性 → 实在不行做企业标准备案

所需数据

材料类型、客户验收条款、现有标准库

决策参数

标准适用性、检测机构资质（CMA/CNAS）、周期与费用

具体痛点

同一指标不同方法结果差 30%，客户不认；企业标准公信力弱

错误成本

检测报告作废重来，交货违约

现有替代

问检测机构销售（天然偏向自家能做的项目）

月网站可解证据高
检测标准CMA企业标准方法验证
🖥 「材料 × 指标 × 现行标准 × 检测机构」映射库，标注哪些只有团体标准/企标
S12

气凝胶保温工程投标算全周期账

销售/BD 负责人

哪些适合网站解决 以及哪些必须线下——诚实比乐观重要

🖥 适合网站解决

  • 材料选型与比价：把各家性能表归一到统一口径（单位热阻成本、同条件换算）
  • 真伪与成熟度甄别：检测方法指南、报告编号公示、TRL 证据清单
  • 政策与标准导航：首批次保险、申报口径、检测标准映射
  • 应用案例与设计节点库：让每个项目不再重新发明轮子
  • 供需双向登记：材料能力 ↔ 应用需求的结构化匹配
  • 展会/竞品情报的结构化沉淀与检索

🚧 必须线下 / 网站只能辅助

  • 中试放大与工艺调试：依赖本产线设备与物料的实测数据，网站只能给方法论与案例参考
  • 样品实测与可靠性验证：台架测试、循环老化必须物理进行
  • 供应商审核与信任建立：现场审核、体系检查无法在线替代
  • 安全/合规的法律意见与现场评估：责任主体在线下机构
  • 大宗工程投标的关系与账期：商务决策在线下完成

可做形态与 MVP 闭环 用户来 → 用什么 → 留下什么 → 如何变好

买方带着「这家供应商能不能用」的问题来 → 查参数库与甄别档案（引用检测报告编号）→ 用选型器出对比结论 → 把自己的实测数据回传成档案的一部分 → 数据越多甄别越准，后来者依赖存量档案

需要建设的数据表
  • 材料参数库（材料/形态/指标/测试方法/条件/数值）
  • 供应商档案（资质/产线/批次数据/履约记录）
  • 应用案例库（行业/工况/用量/运行年限）
  • 标准与政策库（标准号/适用材料/申报口径/地区）
  • 检测报告索引（机构/编号/结论/日期）
信任来源
  • 每个参数标注测试方法与条件原文
  • 检测报告编号可溯源（公开可核验部分）
  • 供应商档案区分「自报」与「核验」，颜色区分
  • 公开案例只收有出处的事实，标注来源与日期
可做产品形态

本站把重庆「33618」体系 18 个新星产业逐一拆成「行业问题地图」：产业链 → 角色 → 真实工作场景 → 触发事件 → 当前做法 → 决策参数 → 具体痛点 → 现有替代 → 哪些步骤值得数字化。产业名录与本地锚点以重庆市人民政府产业地图（2026-08 更新）等公开资料为准；所有痛点结论为有产业依据的问题假设，须经一线访谈验证后才能进入需求文档。本站不构成投资建议。

完成标准：一个不了解该行业的人，仅看这份文档，就能回答——谁在什么情况下遇到什么问题，现在怎么处理，为什么难，哪些步骤值得数字化。
